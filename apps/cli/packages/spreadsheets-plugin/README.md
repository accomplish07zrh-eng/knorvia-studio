# Knorvia Studio spreadsheets

Version 0.2.0 contains newly authored instructions, an image review agent, and a local inspection utility. The package does not include the previous plugin's scripts, templates, images, or text assets.

The skill explains creation and editing through separately installed document tools. Those tools retain their own licenses. No tool or model is installed, selected, or contacted automatically. The bundled inspector is a preflight, not a visual renderer or a full format conformance validator.
