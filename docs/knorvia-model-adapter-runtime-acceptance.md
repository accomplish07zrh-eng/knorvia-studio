日志接口返回 void，不能以函数返回作为异步落盘完成。Patch020 至 Patch022 改为在原 10 秒案例预算内，用最多 4 秒观察新建或发生变化的公共输出；修正一个限额夹具的 session 身份，保留文件大小、轮转数量和内容断言。每次夹具变化后先重建旧门，最终仍为精确 66/9。没有读取候选私有写入队列来判断完成。

v8 为 73/75；v9 为 74/75。v9 清理成功生产记录中的重复 SDK 请求时，仍会丢失连续性不明时的最近上下文。v10 只修 `runner-debug.ts`，把 canonical context 与 SDK 请求副本分开：成功生产记录清理重复 payload，同时保留合同要求的有界 baseline 或 delta。未改变失败、开发、全量保留、流式或异步完成边界。未修改最终 Patch022 夹具，run023 为 75/75。
