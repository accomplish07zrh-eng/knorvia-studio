## 首次失败保留

独立测试作者先冻结 249 案例，再建立旧版基线。old001 为 207 通过、42 失败；通过两次有限独立复核，纠正公共路径、对象浅复制和模拟端口等夹具问题。old002/003 均为 224 通过、25 失败；old004 最终为 225 通过、24 项原定缺陷。旧轮原始日志、冻结及更正依据保留。

候选 v2 首次为 244/249。其中一项是真实 URL 拼写差异：没有 userinfo 的下载错误仍被 URL 归一化，额外增加斜杠。其余四项来自两个夹具接缝：同步写操作未记录已有 `wx` 参数，以及模拟 Git 把 clone 结果放进了 checkout pin 路径。只修这两个接缝，所有断言、输入、时限及允许的依赖不变；old005 再次为精确的 225/24 后才验候选 v3。候选仅改下载错误的有限 URL 去敏逻辑，最终 249/249。

来源通用去敏与下载错误 URL 有各自合同，不能合并成一个“删除所有敏感字段”的行为：两者都删除 userinfo，但 query/fragment 仍保留。该限制在规格中明示。
