## REPL 编译环节

新 `cell-compiler.ts` 根据行为规格和类型契约编写，采用一次语法解析及有序编辑计划。没有读取旧 `instrument.ts` 实现正文，也没有将其翻译、改名或逐行改写。新实现依赖现有独立第三方 Meriyah 解析器；不把该解析器计为自有实现。

先建立 8 组既有行为测试并在原执行器上通过，再切换入口；随后增加括号/对象表达式、内部名字碰撞、import attributes、显式 return 的声明保留及编译边界检查，共 12 组契约测试通过。原编译器源码和对应三个旧 dist 文件已移除。新 CLI source map 引用 `core/dist/repl/cell-compiler.js`，不引用旧编译器。

执行上下文、取消、同步 VM 中断预算、宿主桥、图片来源和 CUA 身份收集仍使用既有边界，尚未计为独立替换完成。界面源码、样式和图标没有修改。

新审计工具及编译器/新测试采用 MIT，逐文件摘要和依据在 `licensing/reviews.json`。根 Apache-2.0、现有宿主的许可及第三方声明继续保留。桌面资源清单已添加 MIT 正文；本轮不宣称已完成安装包验收或新版本发布。
