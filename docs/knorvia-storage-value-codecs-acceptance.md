## 明确限制

动态可变 getter 存在有限差异：旧真值身份读取两次而新一次；新合法 task/title 分支可能再次读取；part 的 switch 读取次数不同。正常同步物化 SQLite 行不含这些访问器，规格不承诺其任意读取时序，但不能将本批称为全输入等价。必需 JSON 错误先于 SQL 身份访问仍经过直接验证。

既有 encodeJson 与 fullAccessPayload 声明分别未完整表达 undefined 和原始根值，本批保留实际行为而不扩散修改 SQL 写接口。没有访问真实数据库、供应商、浏览器或设备，未跑真实客户端端到端会话，也未新建跨进程测试；本批是无 I/O 的同步投影边界。
