# 0.8.0-preview.3 发布验收

## 本轮范围

提交当前工作区已完成的 Windows Computer Use、升级与数据保护、启动性能、离线验收、Claude 前端图标和动效，以及用户提供的新官网。安装包加入 Knorvia 黑白品牌画面、中英文引导，首次安装创建桌面与开始菜单快捷方式；保留既有覆盖升级和数据目录保护。

官网只展示安装版；GitHub Release 同时提供安装版与便携版及各自校验文件。安装包和便携包使用同一源码提交与 production 身份构建，旧 Release 不覆盖。

## 打包前已完成的验证

- Node 24.14.0，工作区新鲜度检查通过，开始时 main 与 origin/main 同步。
- `pnpm typecheck` 通过，含桌面 main 检查和 5,422 个中英文键校验。
- `pnpm lint`：0 警告、0 错误；`pnpm fmt:check` 通过。随 Cua 分发的原始第三方许可与生成的许可清单保留原始格式。
- `pnpm architecture:check` 与 `pnpm architecture:check --changed`：违反、基线、新增均为 0。
- `pnpm build:cli-packages`：17/17 成功。第一次因上游驱动下载 TLS 失败未通过；重跑使用此前已缓存的官方 0.30.1 归档，打包脚本重新校验 SHA-256。
- `pnpm test:studio`：900/900 通过，0 跳过，耗时约 211 秒。
- 新官网交互验收：390、768、1440、1920 四种宽度无横向溢出，内嵌图片解码、外观切换、音效按钮状态、安装包与校验入口、发行说明检查通过，无未捕获脚本错误。
- 安装向导品牌资源通过本机 NSIS 编译夹具检查。未在用户当前系统执行真实安装/卸载，避免改变现有安装和个人快捷方式。
- Gitleaks 对待提交源码快照扫描：28 个候选均逐项核验为文件摘要或脱敏回归的固定假凭据，按精确指纹排除后 0 个发现。已有 `.env.development`、`.env.production` 和 CLI 模板是受版本管理的公开构建配置，也纳入了扫描；没有提交本机密钥、私钥、便携包或真实 `data/`。
