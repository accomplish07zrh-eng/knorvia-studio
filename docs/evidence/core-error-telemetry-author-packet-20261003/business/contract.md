# Provider business-error classification contract

Own synchronous classification/summary projection only. Do not make provider/network calls, mutate provider records, parse credentials, log or own canonical state. Public APIs/private referenced failure interface/imports are supplied; unchanged isPlainRecord/createCoreError remain opaque collaborators. Exact priorities/schema/data in output-data are retained contract expression.

Metadata lookup: falsy metadata returnsundefined. Otherwise breadth-first queue starting with that exact input, one fresh WeakSet. Remove next from front; skip falsy or nonobject, skip alreadyseen, add objectbefore processing. Arrays enqueue each item by for-of (live iterator/holes yieldundefined) thencontinue WITHOUT code/message/failure reads. Ordinary objects evaluate code normalization pass FIRST, then independent message pass, then record.success===false, then nonzero normalized-code classifier. Even successfalse does not skip either prior pass. Failure returns keys message (normalized or exactfallback),providerCode (ownundefined included),responseBodySummary (ownundefined included), in that order. Stop on first breadth-first failure; no bounded depth/extra allsiblings-search/reclassification. If notfailure, Object.values(record) snapshots enumerable values and enqueues only truthy typeofobject items in that order, including arrays, with cyclic references skipped later. No scalar nested JSON-string parsing. Getter/collaborator exceptions propagate. No global seen cache.

Both code/message pass separately capture nested error and context BEFORE checking top-level candidates: isPlainRecord(record.error) then, iftrue, re-read record.error for capture; same for record.context. Do not reuse captures across code/message passes. Returned capture can invalidate; optional field access handles null/undefined normally. After those captures evaluate candidates in exact ordered lists from output-data, LAZILY nullish-first (don't eagerly map all property values). Code: finite numeric values →String(Math.trunc(value)); strings →trimmed iff nonempty; other/nonfinite numeric→undefined. Message: strings trim nonempty elseundefined. Nonzero code: falsynormalized→false; Number(value) then finite→numeric!==0, nonfinite→true. String0/0x0/emptytrim reflect ordinary Number gates, not invented business-code allowlist.

Unknown error conversion: falsy/nonobject→undefined (arrays can be object records here, unlike metadata array expansion). Read isProviderBusinessError===true first OR record.name===ProviderBusinessError (short circuit). Ifmarked, classify that RECORD directly; marker does not force failure, and skip context overlay entirely. Otherwise capture context using isPlainRecord(record.context)?second record.context:undefined; if capturedcontext truthy, construct overlay by spreading it first, then msg=context.msg??context.providerMessage??record.message, message=context.message??record.message, code=context.providerCode??context.code in that evaluation/insertion order. Classify overlay with same code/message/success/summary rules; iffailure return it. Else classify original record. No recursion through cause/errorchains except the explicitly captured nested code/message fields. A generic Error name/message without a nonzero code/successfalse is not business failure.

Core wrapper if nofailure returnsundefined; else delegate createCoreError(ModelError,failure.message,{context:{optional providerCode truthy test then reread, optional responseBodySummary truthy test then reread},recoverable:true,retryable:false}). Context optional fields omitted when falsy, order from output-data; do not add source/model labels/metadata payload. Delegate exception/type/code/timestamp generation, preserve receiver/call order.

Response summary is intentionally the EXISTING bounded-by-type projection, not a new redaction policy: create fresh ordinary {}. Snapshot Object.entries(record) once; ignore undefined; copy string/number/boolean (including nonfinite numbers) by ordinary key assignment; copy array iff native every sees only string items (empty/sparse arrays satisfy as nativeevery dictates), retain exact arrayreference; ignore null/nested object/mixed arrays/functions/etc. Keep enumerable key insertion/order and ordinary assignment semantics; no Object.fromEntries/nullprototype/new recursive copy. Return summary iff Object.keys(summary).length>0, otherwiseundefined. No maximum key/value length or arbitrary field-name deletion invented. Primitive metadata fields/strings may be retained as before; don't claim blanket credential/PII redaction or a new grant. Probe only synthetic type/cycle/classification/canonical-preservation boundaries, never actual data.
