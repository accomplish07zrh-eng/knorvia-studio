## Public surface and dependencies

initializeRuntimeTooling(runtime: AgentRuntimeInternal, deps: AgentRuntimeDeps, sessionId: SessionId): { executor: ToolExecutor; hookRunner?: HookRunner } is synchronous. Runtime and deps are caller-owned; no cache, cloned runtime, task state, retries or new grants. Lower permission/notification/search/shell/memory/session-mode policies are unchanged imported ports. See imports.txt. Use their declared results without substituting policy.

## Initialization and registration

Registration happens first, hook assembly second, executor selection last. Failures propagate synchronously and prevent subsequent steps. Supplied deps.toolExecutor is used by nullish selection, but registration and hooks still happen. Return keys executor then hookRunner, with hookRunner present even undefined.

Before registration options are constructed, read runtime.config.runtimeFeatures?.nodeRepl and compare strictly to true, then read browserUse === true and, only then, deps.browserControlPort !== undefined. A present null browser port counts present. Pass runtime.registry unchanged to registerBuiltInTools.

Registration option keys and evaluation order (including undefined fields):
1 bashTimeoutPolicy=config.bashTimeoutPolicy; 2 includeSkill=Boolean(runtime.skillPort); 3 includeAgent=Boolean(runtime.subagentPort); 4 includeSendMessage=runtime.subagentPort?.sendMessage !== undefined; 5 includeRespondToCoordinator=config.taskType===subagent_child && Boolean(deps.coordinatorResponsePort); 6 includeSubmitResult=Boolean(deps.workflowSubmitPort); 7 optional submitResultSchema: omit only when deps.workflowSubmitSchema===undefined, otherwise read it again as value; 8 includeEscalate=Boolean(deps.workflowEscalatePort); 9 includeWorkflow=Boolean(deps.workflowPort); 10 includeAutomation=Boolean(deps.automationPort) && taskType!==subagent_child; 11 includeOffPeak analogous deps.offPeakPort; 12 includeDynamicWorkflow=resolveRuntimeDynamicWorkflowToolsIncluded(config); 13 includeNodeRepl=captured first decision; 14 includeBrowserUse=captured browser decision; 15 embeddedSearchEnabled=resolveRuntimeEmbeddedSearchEnabled(runtime); 16 agentProfiles=config.subagents?.profiles; 17 allowedTools=resolveBuiltInToolAllowlist(config); 18 disallowedTools=resolveRuntimeDisallowedTools(config).
The existing helpers own aliases, exploration intersection, child control, workflow structural denial and false-only workflow disable. SubmitResult and Escalate use their ports, not task scope. Never widen these gates.

## Hook and mailbox lifetime

Use deps.hookRunner by nullish selection. Otherwise configured hooks exist iff (config.hooks?.enabled OR deps.workspaceHookSnapshot) AND deps.executionPort is truthy. Configured factory option order: config=config.hooks ?? shared fallback {enabled:false,events:{},maxOutputBytes:32768,timeoutMs:60000}; emitEvent; executionPort; getWorkingDirectory; logger; workspaceHookAdmission; workspaceHookSnapshot. Configured emitEvent is a native async callback which awaits runtime.appendEvent(event, getCurrentTraceContext() ?? runtime.rootTraceContext), on runtime receiver; no stale check. Directory callback reads current workingDirectory each invocation.

If deps.sessionMailboxPort is falsy return selected hook identity. Otherwise make an in-memory runner only when none exists. Its option order is emitEvent then logger. Its native async emitter returns immediately for isStaleBranchRuntimeTaskEvent(runtime,event), otherwise awaits appendEvent with the same trace fallback. Do not add awaits to the no-op path or wrap another async callback.

Call createSessionMailboxHookRegistrations with keys enqueuePendingInput, mailbox (read deps.sessionMailboxPort again), sessionId (the initialize argument). enqueuePendingInput is native async: await runtime.steerTurn({delivery:guide,expectedTurnId:traceContext.turnId,input,traceContext}) on runtime. Rejected result warns on runtime.logger receiver with exact text below and context ordered as traceContextToLogContext spread, event=session.mailbox.queue_rejected,module=core.runtime,reason=result.reason,status=completed. Accepted result has no warn. Port errors/rejections and logger throws propagate unchanged. For each returned hook, check `register` membership on runner, check typeof runner.register is function, then invoke runner.register(hook) on runner; reentrant behavior remains port-owned. No duplicate registrations, no added admission or abort checks.
