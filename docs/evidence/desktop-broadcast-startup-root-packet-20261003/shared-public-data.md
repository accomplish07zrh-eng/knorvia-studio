# Shared public schema/type/port qualification

Reuse canonical @knorvia/shared schema/constants and @knorvia/services BroadcastMessage. These notes describe public data, not implementations of schemas or native adapters. Native Electron declarations remain opaque imports; bounded native call contracts below are not a full external module declaration or semantic type closure.

BroadcastMessage has channel:string, payload:unknown, optional sourceWindowId:number. broadcastMessageSchema validates channel using trimmed nonempty string, payload unknown and optional integer sourceWindowId, with canonical Zod object behavior. The hub uses parsed outputs and its sourceWindowId override. Host broadcast envelopes are type=broadcast/message; request data is type=broadcast-claim-request/requestId/key; commit/release is the corresponding type/key/claimToken. RequestId/key/claimToken use canonical trimmed nonempty string; key additionally has max length1024. Original hostResponseMessageSchema is the canonical larger discriminated type union, including unrelated variants; import it rather than narrowing/recreating it. safeParse returns success/data or failure/error; keep schema method receiver. Existing formatZodError returns string for canonical ZodError and is called only at the two hub warning sites.

DatabaseStartupState required fields: schemaVersion literal1; startupId and attemptId string length1–128; sequence nonnegative integer; startedAt and updatedAt finite nonnegative numbers; phase; disk array(max8). Optional fields: databasePhase, migration, currentMigration, migrationBaselines, finalDatabase:boolean, failedPhase, errorCode, sqliteCode:integer, systemCode:string(max64), migrationId:string(max128). Own-property absence remains distinct from undefined; relay does not rebuild these records or validate receive.

phase/failedPhase vocabulary in order: starting, preparing_host_storage, preparing_session_storage, starting_services, ready, failed. databasePhase vocabulary: checking, waiting_for_lock, migrating, committing, maintaining, ready. Error-code vocabulary: storage_full, permission_denied, io_error, out_of_memory, corrupt, open_failed, lock_timeout, checksum_mismatch, newer_database, backup_failed, sql_failed, startup_status_timeout, transport_closed, unsupported_runtime.

Disk summary fields: scopeId:string(max128), observedAvailableDropPeakBytes and minAvailableBytes finite nonnegative number|null, quality=complete|partial|unknown, sampledAt finite nonnegative number|null; canonical object is strict. Migration facts: kind=none|initialize|upgrade, executedCount and committedCount nonnegative integers, optional lastAppliedMigrationId:string|null. Canonical migration ID validation regex is /^[a-zA-Z_0-9-]{1,128}$/. Canonical migration fact validation requires committedCount<=executedCount and kind none implies executedCount=0; leave these rules in the original schema owner. migrationBaselines entries: databaseId:string(length1–128), databaseKind=tasks-index|session, optional lastAppliedMigrationId with the same canonical ID/null shape; strict object. databaseStartupStateSchema itself is strict; relay only consumes its public state type.

databaseStartupControlSchema is the canonical strict action-discriminated union: snapshot with no other fields; exit with no other fields; retry with attemptId string(length1–128). The relay consumes parsed result.data by identity, without implementing retry policy or correlating the attempt itself. Startup port payload data is sole databaseStartupId:string; getDatabaseStartupPortPayload's original truthiness rule is in its contract, while canonical payload schema validates length1–128 at its own boundary.

Relevant native ports: UtilityProcess.on(message, callback(raw:unknown)), once(exit, callback) and removeListener(exit, exact callback), postMessage(payload) with child receiver; BrowserWindow.once(closed, callback), removeListener(closed, exact callback), isDestroyed(), current webContents identity with isDestroyed()/send(channel,state) and preserved receiver; ipcMain.on/removeListener(channel, exact callback). Control event.sender is native WebContents identity. No extra frame metadata, liveness check or protocol interpretation is supplied. Native event callbacks may execute synchronously/reentrantly through fake ports in later bounded review; current preparation executes none.

Imported randomUUID supplies string on each required call; Date.now supplies numeric wall-clock samples. Required sampling order and exception effects are in each contract. logger.warn accepts arbitrary arguments; imported telemetry accepts the original DatabaseStartupState and returns void. Canonical module implementations, native internal state and body details are not supplied to the eventual author.
