# Stored shell snapshot owner

Implement the complete API in api.d.ts with the imports in imports.d.ts. Private representation is your choice. No old source/history/tests/oracles are author inputs. Fixed runtime literals are in literals.json; no licence/header change.

Persistence: native async function. A missing/falsy selection or missing saveSessionEntry returns without clock/save. Inside the recoverable catch, read Date.now once; save an entry with ordered keys id,sessionID,type,time,data. ID is sessionId + ':runtime:bash_shell_selection'; type is imported SESSION_ENTRY_BASH_SHELL_SELECTION. time ordered created,updated both same timestamp. data shallow-clones selection and independently shallow-clones display, preserving unknown supported extra properties and their order. Await save with store receiver. Any thrown/rejected failure in that region goes to exact warning metadata (trace first,errorMessage,event,module,status) and then resolves; errors from the warning itself propagate. Do not catch the initial guard.

Read: native async function. Missing sessionEntries returns status missing without read. Inside catch, await entries filtered by ordered sessionID,type; inspect only final entry. Empty array gives missing. Validate data as a non-array object, then display as a non-array object, then read display.name,dialect,source in that order. name must be a string (empty allowed), dialect cmd|posix|git-bash|legacy-shell, source auto-detected|user-config|legacy-fallback. New selected object ordered dialect,display:{name},source; optional id,label,path are copied only when strings, in that order. Unknown data/display fields are discarded. A valid read returns ordered selection,status restored; invalid data warns then returns status invalid. Read/validation/warning failures in the region enter read_failed catch with exact runtime warning then status read_failed. Catch-warning failures propagate. Native await remains even for already settled read promises.

Resume resolution is synchronous. Destructure currentSelection,logger,restore,traceContext once in this order. If status is not restored return original restore by identity. Legacy selection is usable exactly when path undefined or trimmed empty; other dialects require truthy path. cmd path case-insensitively cmd.exe with neither slash nor backslash is usable without access. All remaining paths use accessSync(path,X_OK) inside catch; failure means stale. Usable restored result returns original restore by identity. Stale warning occurs before fallback choice; warning errors propagate. With truthy currentSelection return new ordered reason:'stale_snapshot',selection:currentSelection,staleSelection:oldselection,status:'fallback'; otherwise staleSelection,status:'stale'. References must remain original, no OS execution.

Supporting ports: sessionStore.saveSessionEntry(entry):Promise<unknown>; sessionStore.sessionEntries({sessionID,type}):Promise<Array<{data:unknown}>>; logger.warn(message,fields); traceContextToLogContext(trace) unchanged. No new clocks/retries/validation or post-await admission rules.
