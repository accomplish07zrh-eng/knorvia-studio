# Session resume owner functional contract

Implement all five public exports in api.d.ts, using only existing lower dependency APIs (imports/signatures/ports). Keep runtime as the only state owner. No rewriting E hydration/context, root registry/read-state HOLDs, permission helpers, services or protocols. No retry/new recovery/abort/rollback policy. Whole coordinator owns the following native asynchronous phases; avoid extra awaited phase wrappers. Title synchronization below is a native async boundary that is awaited even when it has no effect. All public strings/log shapes/result fields are fixed by public-text.json. Ordinary fields/references remain live at stated phases; do not globally snapshot runtime/store.
