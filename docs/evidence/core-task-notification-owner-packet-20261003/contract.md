# Runtime task notification public formatting contract

Own only notification.ts as a whole pure public-contract formatter/projection. Preserve exact declared public interface, three local function exports, unchanged workflow helper reexports, original import identities, output prose/XML/entities/size/ordering and input identity. Actual registry, workflow copy and any policy owners remain original imports; do not reconstruct their implementations or send actual notifications. Required prose/static fragments in required-data.json are honestly source-derived preservation material, not originality credit. Do not infer policies/grants from names. Six named author inputs only; do not read original/source/history/tests/other packets. No private helper names, decomposition or bodies prescribed.

All formatters read supplied input without mutating input, nested usage/modelUsage/reports/artifacts/failure or imported objects. Native string/number/undefined/nullish/truthy behavior and synchronous helper errors remain. General XML escaping performs one replacement pass on the ORIGINAL string for < > & single quote double quote to &lt; &gt; &amp; &apos; &quot;, without double escaping newly produced ampersands. Bash and provider multiline error escape only < > &, preserving quote characters. escapeXml is public. truncateTaskNotification is public: when UTF-16 string length <=120000 return exact value; otherwise slice first120000 UTF-16 code units and append newline[truncated], without closing tags or Unicode repair. Local bash bypasses truncation; all other formats truncate their final complete projection, including workflow guidance, once.

Dispatch exact taskType local_agent/local_bash/local_workflow first; every other type uses general shape. Reexports remain aliases to original workflow-notification-copy module, not wrappers.

General shape lines, each joined by exactly newline: opening task-notification; two-space task-id; optional truthy tool-use-id; two-space task-type; optional truthy agent-id; optional truthy subagent-type; optional truthy output-file; optional truthy stdout-file; optional truthy stderr-file; status; optional truthy description; summary; result whenever !==undefined (empty included); error whenever !==undefined; optional usage block; closing task-notification without indentation. Every interpolated string uses full escapeXml. Optional general usage is absent for falsey usage or no present metrics. For each value !==undefined, metrics order total-tokens, tool-uses, duration-ms, modelUsage.inputTokens input-tokens, modelUsage.outputTokens output-tokens, modelUsage.cacheReadTokens cache-read-tokens, modelUsage.cacheWriteTokens cache-write-tokens, modelUsage.reasoningTokens reasoning-tokens. General total-tokens reads usage.totalTokens only, no model total fallback. Usage opening/closing have two spaces and each metric four. Numeric values use native template conversion, not rounding/formatting/XML escaping. Zero values are present.

Local bash lines have no indentation: opening; task-id; optional truthy tool-use-id; optional truthy output-file; status; summary; closing. Values use three-character escape policy. Ignore task-type/agent/description/stdout/stderr/result/error/reports/artifacts/guidance/usage and runStatus. Join newline and return without truncation.

Local agent lines unindented: opening/task-id; truthy tool-use-id/output-file; status (not runStatus); summary; result/error if !==undefined; optional SINGLE usage line; closing. Full five-character escape. Agent usage: absent for falsey usage; token count is usage.totalTokens nullish-fallback usage.modelUsage?.totalTokens, include when !==undefined as subagent_tokens; then tool_uses and duration_ms whenever !==undefined. If no values present omit whole usage. Otherwise adjacent metric tags with no spaces/newlines inside one usage element; no other model metrics. Final truncation applies.

Local workflow lines unindented: opening/task-id; truthy tool-use-id/output-file; status value runStatus nullish-fallback status; stop-reason when !==undefined, even empty; truthy description; summary; result when !==undefined; error; optional reports; optional artifacts; closing. These string values full escape except provider block described below. Workflow ignores usage, stdout/stderr/agent/subagent/task-type.

Provider error: only when failure?.providerStop is NOT undefined call original formatWorkflowProviderStopError(failure,taskId) with exact supplied failure reference and taskId, even regardless of runStatus. If helper result !==undefined emit error opening/newline, three-character escaped helper text, newline/error closing; quotes raw. Else emit full escaped input.error when !==undefined. Preserve synchronous helper exception, no new catch/helper invocation for absent providerStop.

reports/artifacts each emits whenever object !==undefined, even count0/previewempty. Exact open tag has count raw numeric string and shown attribute ONLY when shown<count; no normalization/count clamping/validation. Escape preview with full XML policy, each preview and closing tag on own lines. Reports follow result/error; artifacts follow reports. Truncation therefore removes tail guidance/artifacts before earlier run result. Missing objects omit whole sections; don't generate empty defaults.

Truthy deliveryGuidance appends one empty line and exact guidance (newline-separated paragraphs) after closing XML. No guidance otherwise, including legacy local_workflow. Guidance uses runStatus nullish-fallback status, current stopReason, artifacts!==undefined (even0), taskId and scriptPath as supplied. run ID and path inserted into guidance raw, without XML escaping/quoting/normalization. scriptPath undefined selects old no-file copy; present empty string selects file-aware copy. Exact required prose/template fragments in required-data.json are mandatory. Guidance branch precedence is observable: completed FIRST, then stopReason user/model/provider/interrupted/superseded for ANY other status, then status stopped, status errored, then generic legacy/unknown fallback.

Guidance paragraphs and order:
- completed: exact completed-deliverable paragraph; individual reported-findings/partial-preview paragraph; optional long artifact paragraph (cards/title/primary deliverable); do-not-restate paragraph.
- user: purposeful user-stop/no resume/amend/rebuild paragraph; finished findings/show evidence/stop-and-wait paragraph; optional short artifact paragraph.
- model: TaskStop/fix now/AmendWorkflow/cache/sooner/next-time paragraph with optional script path suffix ONLY when path !==undefined; otherwise-finished/unchanged-only-if-user-wants paragraph; optional short artifacts.
- provider: provider-error/cause/fix/finished findings paragraph; resolve-cause-before ResumeWorkflowRun run_id exact template/no rebuild paragraph; optional short artifacts.
- interrupted: owning-process-exited/finished findings paragraph; ResumeWorkflowRun exact run_id/journal/unfinished paragraph; optional short artifacts.
- superseded: one newer-run/already-running/no resume/no amend/wait paragraph; optional short artifacts.
- stopped with no recognized stopReason: stopped/salvaged findings paragraph; continued ResumeWorkflowRun run_id/ask user template; optional short artifacts.
- errored: script-failed/salvaged findings/failure meaning paragraph; optional short artifacts; then old no-file fix-and-AmendWorkflow/run_id/reuse/refuse replay paragraph OR exact file-aware edit-in-place/AmendWorkflow run_id/path/no inline/reuse/refuse paragraph.
- fallback: did-not-complete/salvaged findings/failure meaning paragraph; optional short artifacts; generic corrected-script-AmendWorkflow reuse or Interrupted-resumable paragraph.
