Draft three complete functions only: initializeAgentRuntime(this:AgentRuntimeInternal,sessionId:SessionId,config:AgentRuntimeConfig,deps:AgentRuntimeDeps):void; beginShutdown(this:AgentRuntimeInternal):void; closeBrowserSession(this:AgentRuntimeInternal):Promise<void>. Curator installs their bodies into the native constructor/methods; no extra function-call/async settlement layer in production. Private representation/locals are author choice. Do not read source, history, tests or oracle. Use imports/types/dependency signatures supplied. Existing field declarations/default initializers and public interface are retained outside your candidate, not your authorship.

Instance fields already exist in original declaration order before constructor. Config/deps are live ports: read at specified phases, do not capture everything at entry. Error values propagate unchanged; no constructor catch, rollback or retries. Constructor is synchronous, creates no new async gate, and ignores returned MCP startup promise.

## Native shutdown boundaries

beginShutdown sets shuttingDown=true first, then optional memoryExtractionScheduler.shutdown(), preserving scheduler receiver. Every repeated call invokes shutdown again; no idempotency guard. Throwing scheduler stops current call after flag write.

closeBrowserSession is native async: call this.beginShutdown(); disposeNodeReplSession(this.sessionId); both OUTSIDE recoverable try/catch. Then await this.browserControlPort?.closeSession?.({sessionId:this.sessionId,traceContext:this.rootTraceContext}), preserving optional method receiver and ordered input fields. Keep an await even when port/method absent. Catch only close/await errors; logger?.warn("Browser session cleanup failed",{error:error instanceof Error?error.message:String(error),event:"browser.session_cleanup.failed"}), with logger receiver, no trace spread. If logger absent, argument evaluation is skipped. Warn errors propagate (no wider catch). Browser cleanup does not cancel/close execution/MCP/store or modify grant/queue policy here. No added abort guards or cleanup calls. Public interface and all other methods remain untouched.
