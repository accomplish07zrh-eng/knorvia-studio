# Manual compaction utilities: functional requirements only

Own only apps/cli/packages/core/src/compact/manual.ts. Preserve every declared API/type/constant and runtime dependency. No source/test/history bodies may be read. Keep the existing contracts and shared constant and rounds collaborator; do not replace them. No persistence, session writes, validation, new service or permission rules. Complete output under 400 lines. Required output prose/constants/data are retained material, not novel author expression. Ordinary idioms require no novelty.

getMessagesToSummarize: exclude every system message, and user messages whose existing modelMessageContentToText projection after trimStart starts with the exact case-sensitive `<system-reminder>`. Other roles are retained regardless of text. The filtering pass precedes the cloning pass, including for callbacks/errors. Each retained message becomes one shallow spread copy, preserving extra enumerable fields and content/tool-call/nested identity. No input mutation.

hasEnoughMessagesToCompact first gets that filtered/cloned list, delegates grouping once to groupByAssistantStartedRounds with only the role accessor (no assistant ID accessor), then returns true only for >=2 groups and at least one assistant. Short circuit assistant search after the group check. Grouping is a delegated public behavior, not owned algorithm: a new assistant starts a round when an existing round is nonempty; leading non-assistants stay their own first round; later non-assistants join current; empty input gives [].

buildManualCompactBoundary returns a fresh plain object. Own fields in order: boundaryId input; trigger input??CompactTrigger.Manual; phase input; compactReason input; summarySource literal model; preCompactTokenCount; postCompactTokenCount; truePostCompactTokenCount; autoCompactThreshold; willRetriggerNextTurn; summarizedMessageCount; keptMessageCount input??0; lastSummarizedMessageId; preservedSegment same input reference; summaryMessageIds fresh single-element array of input.summaryMessageId; customInstructions boolean input.customInstructions!==undefined (empty string counts); traceId input.traceContext.traceId; turnId input.traceContext.turnId. Optional fields are present even when undefined. Do not normalize/floor/validate/deduplicate numeric/ID inputs; no attachment/hook/additional fields. Public schema/types are imported, not reconstructed.

estimateMessageTokens processes messages in order and sums each message's independent Math.ceil(chars / imported ESTIMATED_TOKEN_CHAR_DIVISOR), not a single total ceiling. For string content its exact character length contributes. For array content project reasoning blocks to their text (provider-visible size), other blocks via existing modelMessageContentBlockToText. Project all blocks before truthy filtering and join with two newline characters. Do not change existing visible-text collaborator semantics. Then for each tool call in order add length of name concatenated with JSON.stringify(input??{}) result, defaulting to literal {} when stringify returns undefined or throws. Serialization failures alone are caught; no catch around visible content/blocks/names. Circular, bigint, undefined/null and custom toJSON are governed by this fallback; input references are not modified. Each message with no chars estimates zero; numeric divisor is imported, not duplicated.

getUsageTotalTokens: first observe inputTokens, falling back nullishly to (cacheReadTokens??0)+(cacheWriteTokens??0); then return totalTokens if non-nullish, else that computed input count+(outputTokens??0). Cache terms are not added to explicit inputTokens. Reasoning tokens are ignored. Zero/NaN/negative explicit numbers are unsanitized. The fallback input count is evaluated even when totalTokens exists; output is only read if total missing.

createCompactBoundaryId invokes supplied zero-argument randomUUID once and returns compact_ + its result. Default provider performs crypto.randomUUID as a crypto method at invocation time, not eager/module initialization or an unbound method. Errors propagate. Constant API values/prose are exact in public-api.d.ts: retry count3, retry marker, user message. Retain their inferred literal public types.
