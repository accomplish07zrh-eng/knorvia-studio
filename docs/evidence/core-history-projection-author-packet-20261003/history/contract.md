# Runtime message history: functional requirements only

Own complete apps/cli/packages/core/src/agent/message-history.ts and at most one cohesive private helper if needed to keep each source under400 lines. Preserve public declarations and runtime imports; helper may use type-only backlink; all public functions/types/class remain reachable from original module. Do not add exports to public barrels, recreate contract schemas or change consumers. Do not read target/dependency/test/history/review bodies. No filesystem/network/permission implementation. This owns only in-memory canonical runtime entries/cache stats; provider request projection/persistence remain delegated elsewhere. Query-scope metadata stays projection-only; never create a persistence path. Public schemas, reminder strings/source enums and ordinary projection idioms are retained contract material, not grounds for forced novelty.

One MessageHistoryImpl owns one entries array and one cacheStats object. New instance: entries[], stats own totalMessages0,cachedMessages0,lastCacheHitfalse (no cacheReadTokens field). borrowReadOnlyRuntimeEntries returns the exact current entries array, a synchronous read-only borrow; callers cross async boundary with their own shallow snapshot. Append operations mutate this same array. Init/replace/reset replace the accepted array, so old borrows remain old snapshots. toRuntimeEntries defensively clones each entry via specified public clone; getMessageCount is array length. getCacheStats returns a fresh shallow spread stats copy.

init clears/replaces entries before handling inputs. Nonempty string produces one bare entry with message{role:system,content:identical string}. Empty/absent/nonarray input =>[]. Array input maps every item through entry-input classification/clone before appending; mapping error propagates with entries already emptied and prior stats still retained until recomputation. After success recompute stats own totalMessages length,cachedMessages leading-prefix count,lastCacheHitfalse; no cacheReadTokens. replaceMessages first maps/defensively clones all input items, then replaces accepted array, then recomputes same stats; mapping failure leaves old array/stats untouched. No catch/validation/new recovery.

addUser appends createRuntimeUserEntry. addAttachment appends systemReminderAttachmentEntry. addEntries maps/clones entire supplied list before pushing clones to current array; errors during map append nothing. addAssistant appends exact createRuntimeAssistantEntry semantics. addToolResult default isError = !success only when parameter undefined; explicit true/false overrides success. All append operations set stats.totalMessages to current length only, retaining other stats including cachedMessages and cacheReadTokens. No automatic cache recomputation for append.

setCacheHit sets lastCacheHittrue, own cacheReadTokens to supplied number/undefined without sanitation, cachedMessages=current length (total stays unchanged). setCacheMiss sets lastCacheHitfalse, own cacheReadTokensundefined, cachedMessages=current leading-prefix count (total stays unchanged). reset takes the leading prefix slice, clones each entry, then installs it and stats total/cached both prefix length,lastCacheHitfalse with no cacheReadTokens; no regeneration of prefix/metadata.

Input classification: runtime entry if `message` property is present (in operator, not truthiness) OR present kind equals attachment; otherwise plain ModelInputMessage. Attachment predicate additionally requires present kind === attachment. Other kind values plus message still count as entry. Plain input becomes {message:cloneModelInputMessage(input)}, without metadata field. Attachment with direct-model projection has no representation; historical private diagnostic text: "Runtime attachment entries do not have a direct model message representation". No novel validation or public error is required for malformed runtime inputs; preserve normal typed-input behavior and propagation.

countContextPrefixMessages stops at first nonprefix, never counts later matching items. Attachment prefix only metadata.source context_prefix or skills_listing. Other attachment breaks. Message role system always counts regardless metadata. Nonuser nonsystem breaks. User with any metadata counts only those two source values; otherwise breaks, even reminder-looking text. User without metadata falls back to existing modelMessageContentToText(content).trimStart().startsWith exact case-sensitive <system-reminder>. No projection call for metadata-defined users or system/attachment/other-role entries. Empty list=>0.

Metadata constructors return fresh {source}: given system source; real_user; legacy_synthetic; todo_reminder respectively. isKnownSystemReminderSource returns typeof value===string AND existing SYSTEM_REMINDER_SOURCES.includes(value), preserving short circuit and actual constant (no local registry). systemReminderAttachmentEntry returns own kind:attachment,content input,metadata fresh{source}; no cacheControl initially. createRuntimeUserEntry returns fresh {message:{role:user,content identical input reference},metadata: metadata?shallow spread:undefined}; metadata field always present. createRuntimeToolResultEntry returns {message:{role:tool,content same input reference,toolCallId,toolName,isError}} in that field order; no metadata.

createRuntimeAssistantEntry (also addAssistant): clone each reasoning block by spreading block then own providerOptions set to truthy options?shallow spread:undefined; no reasoning array supplied=>[]. If at least one reasoning block, content is new array of cloned reasoning blocks followed by a new {type:text,text:content} only when content.length>0; otherwise content is exact string including empty. Own toolCalls always present, value supplied?.map selecting exactly id,name,input fields in order (input identity retained, no extra tool-call fields); empty array remains empty. If model truthy, own providerId then modelId included even undefined; otherwise absent. If tokens truthy, own tokens clone included; otherwise absent. Entry has no metadata/kind/queryScope. Tokens clone: spread full object then cache shallow spread, preserving extension fields/reference values elsewhere and zero values.

cloneRuntimeMessageEntry attachment case returns fresh own kind:attachment,content same string,cacheControl truthy?shallow spread:undefined,metadata truthy?shallow spread:undefined. No extra top-level entry fields survive. Nonattachment clone returns fresh message via cloneModelInputMessage, own metadata as cloned or undefined, includes own tokens only if truthy (cloned as above), includes own queryScope only if truthy. Kind:message and unknown extra entry fields drop. Metadata shallow spread preserves optional/extension values.

cloneModelInputMessage is a selective projection, not a whole-message spread: always own role then content clone; if truthy cacheControl include shallow spread; if truthy toolCalls include new array shallow spreading each tool call (extra enumerable call fields retained, input identity shared); if truthy toolCallId include it; if toolName!==undefined include including empty string; if isError!==undefined include including false; if truthy providerId include; if truthy modelId include. No other message fields survive. Absent/falsy gated fields remain absent, not ownundefined.

cloneModelMessageContent: strings identical; arrays always fresh, each block cloned. Reasoning blocks use reasoning clone (own providerOptionsundefined added if absent). Other blocks with a truthy source property receive shallow block spread and shallow source clone; other blocks receive shallow spread only. Other nested values preserve identity; no providerOptions clone for nonreasoning. invalidateRuntimeTokenUsage returns spread tokens, then total,input,output,reasoning all0, then new cache{read:0,write:0}; preserve other outer fields, drop cache extras, do not mutate session/persistence object. Factory returns new MessageHistoryImpl each time.
