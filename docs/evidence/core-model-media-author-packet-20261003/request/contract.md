# Provider-neutral request projection contract

Own one synchronous request-local message projection, no canonical/history/persistence writes or I/O. Keep the supplied public API/imported module contracts. Read useMidConversationSystem first; it defaults on unless exactly false. Create one new ProviderEntryOrigins; pass input.entries to projectIncomingMessageEntries with it; reorder that returned array; conditionally pass reordered entries to projectMidConversationSystemEntries, then always pass its entries to moveLegacySystemRemindersAfterToolResultRun. Determine latest real user on these final entries via origins.hasRealUser before rendering. Rendering is native map admission (captured initial length/holes); collaborators' exceptions propagate. Adjacent user merge stays disabled as fixed retained protocol policy. Different provider serialization remains elsewhere. Messages is a new shallow array of the rendered messages; index map matches their original indices. Do not coalesce neighboring users.

Attachment positioning: consume entries from newest to oldest, retaining entry identities. Attachment-like entries accumulate pending without insertion until a causal stop or exhaustion; pending flush precedes that stop in reverse accumulation, and the final whole array is reversed once. Every flushed pending entry contributes to bubbledAttachmentEntryCount even if it did not change position. A stop is presented input OR a nonattachment whose message role is system/assistant/tool or tool-result-user. Test the stop before the pending-length gate. Presented inputs never bubble. For attachment entries: capture metadata.source once; it must be known, not goal_state_change, and its descriptor cannot be history_continuity; admit only isMeta truthy, provider_visible, and neither tool_result nor real_user channels. For ordinary entries: first exclude non-user and tool-result-user; capture optional metadata.source; no source/real_user reject, legacy_synthetic admits, unknown rejects, mid-conversation source rejects, then descriptor gates as above. Do not read ordinary-message fields from attachments. Descriptor/security registry functions remain opaque unchanged owners. Bubble-stop roles are observed in system/assistant/tool order, followed by tool-result predicate.

Render attachments only after final ordering. Capture source primitive; unknown source throws the exact Error text in output-data. Known sources produce fresh role:user then content:wrapSystemReminderForSource(source, original content); wrap is delegated (escaping belongs to unchanged collaborator). Truthy attachment cacheControl adds a shallow copy; absent/falsy cacheControl adds no own field. Ordinary entries go through cloneModelInputMessage, never a locally invented clone. Runtime entry metadata/tokens/query/marker internals never enter messages. Canonical content must remain unchanged; collaborators retain their own specified projected-marker behavior.

Origins: scan final projected entries from the end for the first origins.hasRealUser result (findLastIndex semantics). For each rendered index, assign sourceEntries at the same index when the current slot is undefined and an entry exists, using origins.representative(entry); do not pad missing undefined slots unless an assignment occurs. A result of undefined is still an own assignment if the entry exists. Keep source entry identity. Real-user diagnostic includes the final index when nonnegative OR input.entries.some(isPresentedInput) is true, short-circuiting that some if already nonnegative; in the presented-but-no-real-user case retain -1, to prevent downstream heuristic guessing. Otherwise omit the field. Read input.entries again at these later diagnostic stages; strippedRuntimeMetaCount uses native filter of truthy metadata on the original input entries. Do not drop unknown metadata from the count.

Cache markers: apply only when applyCacheControl is exactly true, read after render/origin attribution. Only then observe skipCacheWrite and require exactly true for previous-context targeting. On the projected messages remove truthy cacheControl from each non-system message via shallow rest, retaining all other enumerable fields. System cache markers and falsy/own undefined non-system values remain. Scan backward for latest non-system; skipCacheWrite selects the previous non-system, including across intervening systems. If none return no index. Replace only the chosen request-local message with a shallow copy and cacheControl:{type:ephemeral}. Do not mutate canonical message/cache objects. Diagnostic cacheControlIndex is present only when defined.

Return top-level messages, sourceEntries, diagnostics in that order. Diagnostics insertion order: bubbledAttachmentEntryCount, optional latestRealUserMessageIndex, strippedRuntimeMetaCount, optional cacheControlIndex. Required retained policy/data/protocol identifiers/prose are not novel rights claims. Dormant private merge helpers are not a public feature; preserving disabled policy and external import names is sufficient. Keep cloneModelMessageContent runtime import as the existing declared collaborator edge (it belongs to dormant retained content merge policy); no new API or enabled merge behavior. If retaining dormant behavior, strings become one text block, arrays delegate cloneModelMessageContent, neighboring text adds one newline to previous last text, next cacheControl nullish-precedes prior, tool-result users never merge. Do not supply novelty through cosmetic changes.
