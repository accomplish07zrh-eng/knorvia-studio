# Aggregate request media budget contract

Own request-local projection and optional debug log; no canonical/persistent writes, credential parsing or I/O. Public interfaces/return aliases and dependency imports remain existing. Default aggregate budget is40*1024*1024 encoded UTF-8 bytes. Read options.maxMediaBytes first with nullish fallback. Nonfinite or negative values throw delegated ConfigurationError with exact text, context:{maxMediaBytes}, recoverable:true before scanning messages. Negative zero/fractional nonnegative limits remain admitted; no flooring/new coercion.

Latest user protection: if preserveLatestUserMedia is exactly false use -1 without observing latestRealUserMessageIndex or heuristic. Else capture supplied index: accept defined integer >=-1 and <messages.length; -1 explicitly means no real user; invalid/absent calls unchanged findLatestRealUserMessageIndex(messages). Protect all nonzero media in that one message regardless of its role. Native forEach visits messages and array content with captured length/skipped holes; reobserve message.content on the admitted content pass. Count encoded bytes for image/video via Buffer.byteLength(block.dataUrl,utf8); file only when dataUrl truthy and text falsy; all other blocks zero. Zero-byte media is not in budget collection. Collect media refs in message/block order with blockIndex,requestBytes,messageIndex,protected fields. Total accumulation is collection order and can preserve ordinary JS numeric behavior.

If total<=limit return original messages identity plus zero omitted, projected=total, retained=nonzero refcount,total. Do not copy/replace anything. Otherwise total protected bytes first. If protected>limit, create delegated InvalidInput with exact current-attachment error text/data from output-data; context order code,maxMediaBytes,protectedMediaBytes,totalMediaBytes; recoverable:true. Set returned error.code to the shared attachment error code before throwing (crossprocess localization). Do not discard current attachments to satisfy budget; neither message array nor input blocks changes before error. Dependencies/security/loggers remain unchanged.

On admitted omission, start with protected refs retained; remaining=limit-protected. Consider unprotected refs newest message first then newest block, stable ties. Greedily retain only refs whose bytes<=remaining (skip oversized then continue to smaller/older); decrement on retention. Media keys are messageIndex: blockIndex strings, preserving Set size/count behavior. This is encoded aggregate budget, not per-file raw byte validation.

Any omission yields native map over ALL messages, even unaffected/system/string-content messages: spread message then content projection, toolCalls optional shallow-map copies, cacheControl truthy shallow copy else own undefined, in that property order. Strings/nonarrays preserve content identity. Native map first clears collaborator-selected paired text positions to fresh {type:text,text:''}; for each other block recompute media bytes. No local CUA credential interpretation/rewriting. Original content and tool/cache/source objects remain unchanged. Counters: retained=Set size; omitted=allrefcount-retained; projected sums original admitted refs retained by key in collection order; total=original total. Return order messages,omittedMediaCount,projectedMediaBytes,retainedMediaCount,totalMediaBytes.
