# Tool-call name admission contract

Own only synchronous tool-name admission and invalid-result diagnostics. No actual tool execution, permission determination, credential/model configuration, persistence or I/O. Preserve existing public API/type-only Model/ToolCall/Logger/TraceContext imports and runtime deps. Unspecified fields and arguments remain unchanged.

normalizeModelToolCallsForRuntime: falsy calls or zero length returns undefined (not input empty-array identity). Otherwise native map admission snapshots initial length/skips holes. Each result spreads the original call FIRST, then overwrites name after reading original toolCall.name, spreading context, reading providerExecuted,id,index in that order. Context extension keys survive spread; per-call fields overwrite them. New array/call objects, other enumerable fields/references retained, original calls/context unchanged. Valid string name trims to nonempty and returns trimmed text without error/logging. A string whose trim is empty is retained EXACTLY (including whitespace) only when providerExecuted is not exactly true AND toolCallId is a string with trimmed length>0. This client-executed closable empty name is intentionally not made a runtime execution grant. Non-string name rejects even with valid id; providerExecuted exactly true blank rejects; nonstring/blank id rejects blank names. No coercion/id rewrite/allowlist changes. Observe name as argument before context spread, then normalization fields; short circuit provider/id gates.

requireRuntimeToolCallName ALWAYS requires a nonempty trimmed string, including a closable client blank that normalization admitted. Capture name before spreading context then reading id. It adds toolCallId but no toolCallIndex. Do not reuse a permissive admission path to grant execution, and do not infer authority from id. Return nonempty trimmed string; other values reject.

Rejection builds one logContext before checking optional logger: spread delegated traceContextToLogContext(context.traceContext), then event,module,model string from providerId/modelId,modelId (reread),providerId(reread),source,status,toolCallId,toolCallIndex (own undefined allowed). Exact insertion order/log strings in output-data. context.logger?.warn(exact message,logContext) preserves receiver; even absent logger context construction/conversion occurs. Warn comes before createCoreError; if collaborator throws propagate, no fallback. Throw delegated CoreErrorType.ModelError with exact text and options:{context:logContext,recoverable:true,retryable:false}. Retain logContext same identity passed to warn and error. No extra diagnostic content/tool input disclosure. Error type/code/time generation stays delegated. Required protocol/schema/data/prose and ordinary map/spread/trim/nullish idioms remain retained expression; no global grant.
