# Request-local provider entry origins

Own only runtime/helpers/provider-entry-origins.ts. Preserve complete public class/function declarations and actual imports from contracts, message-history, incoming-message and system-reminder/source. No canonical history/provider payload writes, service/persistence/network/permission implementation or imported prompt rewrite. Existing format/parse/wrap/isMidTurn/attachment collaborators stay opaque. Source<400lines; read only packet/own outputs, no implementation/dependency/test/history/review bodies. No new public API or cosmetic novelty requirement.

One ProviderEntryOrigins instance owns a request-local WeakMap from entry object identity to readonly origin arrays. get(entry) returns exact stored array including empty [] if present; otherwise a fresh singleton [entry] every call. No clone/cache write in fallback. set(entry,inputs) selects map/its set receiver before input flattening, stores fresh result of inputs.flatMap(input=>this.get(input)) (one-level flatten) in input order. Dynamic this.get method receiver/overrides remain observed; no dedup, validation, deep clone or original-input array retention. Origins flatten previously recorded ancestry at set-time, including prior self mapping, then overwrite entry mapping. Input/map failures propagate; no partial update before flatMap completion.

Canonical real-user predicate short circuits in order: not attachment; queryScope!==output_token_continuation; message.role===user; falsy message.toolCallId; falsy message.toolName; metadata absent OR metadata.source===real_user. It does not depend on inputPresentation, content or origin type. Empty call/name values are falsy. hasRealUser calls this.get(entry) once and .some with that predicate. representative calls this.get(entry) once; first .findLast canonical real user; if none .findLast nonattachment; returns exact input entry orundefined (attachments-only/empty). No first-match/reversed copy or new history mutation.

isPresentedInput calls actual parseRuntimeInputPresentation(entry.metadata?.inputPresentation) and tests result!==undefined; no local enum parsing/registry/caching.

projectIncomingMessageEntries maps the supplied entries to a fresh array, preserving sparse/captured-length map semantics and order. Attachment or nonuser=>same entry without presentation parsing. User =>parse metadata presentation once; falsy presentation=>same entry. Observe content after parsing. Nonstring content with any block.type!=text=>same entry without formatter/wrapper/origins call. Empty arrays/alltext pass; body=string unchanged or text block values joined single newlines (only type:text values, empty fallback for others). Call formatIncomingMessage(body,presentation) once. Only exact task_notification then wraps formatted text via wrapSystemReminderForSource(incoming_message,formatted); all other presentations use formatted as-is. After formatting/wrapping call isMidTurnInputPresentation(presentation) once.

Mid-turn true =>fresh attachment with own kind attachment,content formatted/wrapped text,metadata fresh source incoming_message,inputPresentation presentation (drop message/cache/tokens/queryScope/other extras). Otherwise fresh shallow entry spread plus message shallow spread with content overridden, retaining metadata/token/tool/cache/nested references and extras. Call origins.set(projected,[original entry]) exactly once with origins receiver after complete projected construction, before returning projected. Untouched entries never receive mapping writes. All errors propagate; no catches, new cancellation or permission rules.
