## Execution result projection

`toBashOutput` is one native async function. Initial reads capture stdout.artifactPath, stderr.artifactPath, choose stdoutPath ?? stderrPath, then stdout.artifactBytes, stderr.artifactBytes. persistedOutputSize is undefined when chosen path is falsy; otherwise sum *observed stream bytes*, adding each stream only when that stream's artifactPath is truthy. artifactBytes are separately preserved and must never substitute for observed bytes.

Before image work call appendBashCwdStderrSuffix(result.stderr.text || result.error?.message || "", options.stderrSuffix), then interpretBashReturnCode(input.command,result), then isBashProviderErrorStatus with own fields `{exitCode,returnCodeInterpretation,status}` (in that order), then capture result.stdout.text. Provider error skips both image preparation and GH hint, and adds no await. Otherwise call prepareBashImageOutput({artifactPath:capturedStdoutPath,artifactSize:capturedStdoutArtifactBytes,inline:capturedStdoutText},exactContext) and await it exactly once here. No extra awaited helper, catch, retry or abort check. A throw/rejection propagates unchanged. Delayed image completion allows subsequent live result reads; do not pre-capture the whole result. Select image?.stdout ?? capturedStdoutText; isImage is whether image return !== undefined, not stdout truthiness. Then on non-provider-error call getGhRateLimitHint(input.command,result.stdout.text) with a fresh stdout text read.

Pass one output record to attachToolExecutionTelemetry; own field order/presence is:
stdout, stderr, interrupted (timedOut || cancelled), isImage, noOutputExpected (isSilentBashCommand(input.command)), status, exitCode, signal, timedOut, cancelled, stdoutTruncated, stderrTruncated, stdoutBytes, stderrBytes, rawOutputPath (chosen path), dangerouslyDisableSandbox, returnCodeInterpretation, persistedOutputPath (same chosen path), stdoutPersistedOutputPath, stderrPersistedOutputPath, persistedOutputSize, stdoutPersistedOutputSize, stderrPersistedOutputSize; then ghRateLimitHint only when truthy. Fields preceding the optional hint exist even if undefined. Dynamic reads for this record occur in the displayed order, after image completion. Retain the exact attach return identity.

Only after output record evaluation first read options.progressTiming, then calculate telemetry: read sum stdout.bytes+stderr.bytes, then captured progressTiming?.firstOutputMs (undefined differs from0), then construct detail.kind='command', command fields ordered runMs=roundNonNegativeMs(durationMs),firstOutputMs,noOutputMs=firstOutputMs ?? a second roundNonNegativeMs(durationMs),exitCode,timedOut,outputBytes,category=classifyCommand(command),spread classifySafeCommandIdentity(command),status,hash=commandHash(command). Status priority: timedOut truthy→'timed_out', cancelled truthy→'cancelled', completed with defined nonzero exitCode→'failed', else current status. Pass this telemetry object through compactToolExecutionTelemetry, then attach. Helpers retain their existing privacy behavior.

Background telemetry calls compact once with detail.kind command and ordered command fields category=classifyCommand, identity spread, status='backgrounded',hash. Empty telemetry uses ordered command category='empty',count=0,name='empty',status='completed',hash, then compact. No result launch, image or attach in either. All getters/helper errors keep native ordering and propagation.

## Model-content selection

formatBashModelContent first calls BashOutputSchema.safeParse on exact input; failure returns string unchanged, else JSON.stringify(input) ?? String(input), with JSON failure caught then String(input); coercion failure propagates. On parsed data, nonempty array structuredContent wins and returns that exact array. Otherwise provider-error check wins over image parsing; it is the public isBashOutputProviderError, which admits only non-null objects excluding arrays and delegates once to isBashProviderErrorStatus. Provider errors return text prefixed `Exit code {exitCode}`. For other results, truthy isImage allows parseImageDataUrl(stdout,{allowWhitespace:true}); a parse result returns one block `{type:'image',mediaType,dataUrl}` in that field order. Failed/no image parse falls through to text.

Text parts evaluated left to right: stdout, stderr, background info, staleReadFileStateHint?.trim() ?? '', ghRateLimitHint?.trim() ?? ''. Provider-error text evaluates its exit-code string first. Remove falsy parts then join newline. stdout falsy becomes ''; otherwise remove only leading runs matching `^(\s*\n)+` and trimEnd. For non-backgrounded status choose persistedOutputPath ?? rawOutputPath; truthy chosen path envelopes processed stdout. Backgrounded status skips persisted path reads for this stdout stage.

Byte sizing for the envelope: numeric persistedOutputSize wins (including nonfinite); else if either stdoutPersistedOutputSize/stderrPersistedOutputSize is numeric sum each nullish value with0; else sum stdoutBytes ?? Buffer.byteLength(stdout,'utf8') and stderrBytes ?? Buffer.byteLength(stderr,'utf8'). Do not silently change permissive arithmetic of these existing values. Envelope delegates to existing formatPersistedOutputEnvelope with own content,formatBytes,originalBytes,persistedPath,previewChars=2000 fields in that order. Byte callback: nonfinite or<=0→'0 bytes'; <1024→'{bytes} bytes'; next units KB/MB/GB use base1024, one decimal, remove a final '.0', no space before unit.
