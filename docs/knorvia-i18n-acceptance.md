# 中英文文案对齐验收（T3.3）

日期：2026-09-25，Windows，Node v24.14.0。

新增 `pnpm i18n:check`，读取应用实际合并的英文和中文消息对象，核对键、非空值及单括号占位符。根 `pnpm typecheck` 先执行它；现有 Windows 离线 CI 运行根 typecheck，因此后续只在一种语言新增键会阻断该检查。双括号工作流语法是字面文本，不当作替换变量；两处原本有意留空的英文拼句片段有明确例外。补齐了中文 `settings.memory.viewer.disabled`，没有新增记忆页面。

| -------------------------------------------------- | ---------------------------------------------------------------- |

| `node --test packages/ui/test/i18n-parity.test.ts` | 3/3 通过，覆盖缺键、空值、占位符不一致、允许的双括号与空片段     |

限制：本检查只能证明键和简单占位符对应，不能判断译文语义、语气或布局是否恰当；复杂 ICU 模板不在当前 `formatMessage` 实现范围内。用户要求跳过人工目视复核，因此这处中文新增文案没有人工界面验收。该任务没有生成新便携包；桌面上已有便携版仍是上一轮构建。
