运行历史的逐文件审阅改用原 GUI 的 `DiffViewer`，展开文件时才挂载文字差异视图。新增与删除文件用空侧呈现真实增删；二进制或无法读取的文件明确说明没有文字预览，不把其内容显示成空文件。每个文件独立应用。若源文件在隔离后偏离原始版本与成员版本，审阅卡说明冲突并禁用应用；预览后源文件再变更时，Host 应用前的重新校验仍会拒绝覆盖并将错误留在弹窗中。目标路径只取自 Host 返回的相对路径。
