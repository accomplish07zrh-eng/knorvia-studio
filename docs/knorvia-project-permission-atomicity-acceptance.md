# 项目权限原子更新验收

固定基线为 `1034f17`。先行规格 `specs/knorvia-project-permission-atomicity.md` 明确 SQLite 为唯一提交 owner，core 继续持有规则合并算法。新接口把同步变换交给存储 owner，在取得写事务后读取最新规则、变换一次、序列化、写入和提交；事务中没有 await，也没有新增进程内队列或权限缓存。

## 来源与范围

已接触原源码，不作无接触声明。新实现将规则和模式表示为同一组受控存储单元，SQL 由固定列合同和绑定参数组成；独立事务执行器拥有准入、变换和提交/回滚，repository 只保留公共读写合同。来源判断依据为先行规格、存储单元设计和事务所有权实现，不以改名、拆文件、有限对照或测试通过单独证明。既有表名、列名、键、JSON 字段、文案及 SQLite 原生事务语义不主张为原创发明。

仅三份 repository 实现、新可选更新端口，以及明确新编写的测试和文档记录相应来源。此前已独立替换的 core 权限持久化层新增能力选路并重新绑定摘要。大 SessionStorePort、SqliteSessionStore facade、导出 barrel、JSON/codecs、迁移与相邻仓储保留适用许可；少量委派和导出增量不代表整个大文件完成独立替换。根 Apache-2.0、0.8.0-preview.3、现有 UI 和历史发行不变，整仓 MIT 与最终稳定发行尚未完成。

## 行为与边界

只读复核在新建的内存 SQLite 和真实旧 repository 上确认：两个普通并发项目授权均先读取旧值，后一次全量保存覆盖前一次。新 SQLite 能力使用 BEGIN IMMEDIATE，再读取当前规则并调用 core 的合并变换，成功时返回已提交、与回调对象分离的序列化快照。临时文件库中两独立进程各追加八次，最终十六条全部保留且每个写者内部顺序正确。

同连接已有事务在 BEGIN 前拒绝，保留原事务及其写入；BEGIN 或锁等待失败不调用 updater，也不回滚别人的事务。读取、变换、序列化、SQL 和提交失败回滚自己的事务；回滚本身失败同时保留两个原始原因，不返回成功。新端口固定入口 projectID，拒绝 Promise 结果和非对象 JSON 根，保留未知成员；这些约束不收紧旧显式 save。

只有缺少 local 行时回退旧 permission 表；local JSON null 不回退，坏 JSON 报错并保留原值。规则和模式保持各自的键与时间戳合同。core 优先选择可选原子能力，保留方法 receiver 和原 updates 引用，失败不回退覆盖。旧外部 store 没有该能力时保留旧读取/保存及微任务时点；这些旧写者、旧程序、直接 SQL 或显式全量替换仍可能覆盖结果，不宣称混合版本写入全局原子。提交后 logger 抛错仍保留已提交的项目授权并阻止后续会话阶段。

## 回归、复核与产物

先行 16 项测试最初有一项夹具误把 logger 当作 store 时间线事件，修正夹具后旧版为 **4 通过、12 预期失败**。第一版新实现 16/16 通过。只读复核发现两个兼容边界：可选能力探测导致旧 owner getter 多读一次，以及 toJSON 可以将规则对象转换为真值标量/数组。新增五个回归后为 **16 通过、5 失败**，修复后含跨进程共 24/24 通过。再补目标项目捕获、坏 JSON 读失败及回滚双原因，最终 **28/28 通过**。

子进程测试只访问测试创建的临时 SQLite：双进程追加、现有写者释放后读取最新值、短锁等待超时不调用变换且不影响原写者。测试用 IPC 协调，不靠固定睡眠；清理只关闭本测试进程/连接，并检查临时目录边界。只读复核另比较三组旧 save 投影、未知字段及微任务时点，确认 BEGIN 和回滚故障原因保留；它未单独完成跨进程或编译产物检查，这两部分由主代理运行。

固定旧版的源码和编译产物分别通过 **288 个 repository 场景、84 个 legacy core 场景**：读写、legacy/local 优先级、异常、时间戳、模式、序列化结果、getter 次数及微任务轨迹。新并发保证作为有意修复另外验证，不混在旧行为等价中。有限枚举不证明任意 Proxy/重入、恶意回调、所有外部 store 或真实设备场景等价。

编译公开 `createToolExecutor` + `SqliteSessionStore` 通过三场景、13 个断言：两个项目授权通过原子入口都保留；存储拒绝时不启动工具；成功返回快照不会被外部修改回写且非法根被拒绝。五份相关运行时代码与 CLI source map 中的内容一致；三个 contracts 声明出口包含新能力。全部数据库为新建测试库，没有访问真实用户数据、模型、浏览器或设备。
