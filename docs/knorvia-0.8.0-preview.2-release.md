## 本版提供

沿用既有能力：模型供应商配置、内置与本机 CLI/ACP 对话、群聊与工作流、SSH 工作区、图片与视频创作、八个内置插件。首次使用可选择供应商、本机已探测 CLI 或稍后配置；设置中可手动预览并导出诊断包；更新检查默认没有地址，不会自行联网。没有 Knorvia 账号登录，也不附赠模型额度。

本版相对上一预览版新增或加强：

1. **同提交发布门禁**：检查与打包绑定同一提交，发布必须先通过质量检查；同一版本重跑时校验标签目标与附件 SHA-256，一致则幂等结束、不一致则拒绝，不再覆盖已发布字节。
2. **升级与便携数据保护**：数据库迁移前先做一致快照（`VACUUM INTO`），备份失败或数据版本过新时停止写入并保留原库；便携版覆盖只更新程序文件，`data` 逐文件校验不变。
3. **内核分层状态**：区分「未安装」与「已安装但协议失败/超时/被取消」，逐阶段显示状态、原因与耗时；重新探测可绕过缓存；发送前按内核真实能力校验，不支持时给出可解释拒绝，不会静默切换模型或扩大权限。
4. **可信交付摘要与接纳**：按证据给出「已产出/已核验/未验证/结果未知」，只有 Host 哈希与应用日志、创作记录能提升结论，模型自述不算证据；审阅卡支持多选批量应用，并记录接纳的操作标识与文件版本。
5. **工作流引用与参数**：节点可声明参数（默认值/必填/类型），运行前冻结输入；结构化输出引用在 Host 侧校验来源、归属、身份、路径与版本；条件分支仍是受限语法，不执行任意脚本。
6. **工作流场景**：发布检查、代码审查、文档整理、内容与配图交付包四个模板声明少量参数与证据规则；代码审查声明真实只读权限，在不支持强制只读的内核上运行前拒绝；配图不可用时标记未验证而不是占位。
7. **创作参数复用与来源**：保存可复现的参数快照与来源关系（凭据绝不入快照），历史卡片提供沿用参数、变体、作为参考继续生成；对远端结果只做只读核验，绝不自动重发付费请求。
8. **性能**：运行历史有界化（挂载耗时约减半、DOM 节点 3613 → 726，可完整展开还原）；两个数据库并行准备，冷启动约减少 250–300 毫秒。
9. **技能包与兼容面板**：三个原创技能包（项目交接、资料整理、文档质量检查）与设置内只读兼容面板，逐能力显示可用/不可用/未验证，未验证不会被显示成已支持。
10. **受限 Computer Use**：仅提供受限契约、失败关闭门禁与默认关闭的实验开关。**本版无法观察或操作桌面**，开关打开也不会启动任何 Helper。

## 已知限制与注意事项

- 安装包未签名，Windows SmartScreen 可能提示；首次运行请核对上表哈希。
- 使用第三方模型或 CLI 前需自行确认连接、认证、费用与条款；内核探测成功不代表已登录，也不代表账号可用。
- 中断后显示「结果未知」时应先核查再重试；创作任务在远端可能仍在运行或计费，本版只提供只读核验，不会自动重发。
- Computer Use 默认关闭且当前不具备观察能力；不要把它当作可用的桌面自动化。
- 便携版升级前请先退出应用。

## 恢复与回滚

1. **程序回退**：用上一版已验证的便携构建重新执行 `scripts/deliver-portable.ps1` 覆盖程序文件，脚本会保证 `data` 不被替换。
2. **数据恢复**：应用完全退出后，用升级时生成的 `<数据库>.pre-<起点>.<时间戳>.bak` 覆盖回数据库并清除同名 `-wal`/`-shm`；详细步骤见 `docs/knorvia-upgrade-protection-report.md`。
3. **便携数据**：不要删除 `data`；若要彻底清理用户数据，请先确认备份需求后手动处理应用显示的数据目录。
4. **诊断包**：只在用户手动预览、确认后写到本地；导出前请检查其中的日志摘要。
