# Knorvia Studio 0.8.0 预览版（Windows x64）

本地预览交付：`0.8.0-preview.1`。安装包与便携 ZIP 使用同一份应用构建；便携版将数据保存在解压目录内的 `data`。这是本地交付，尚未公开发布或配置自动更新地址。

本版提供模型供应商配置、内置与本机 CLI/ACP 对话、群聊和工作流、SSH 工作区、图片与视频创作，以及八个内置插件。首次使用可选择供应商、本机已探测 CLI 或稍后配置。设置中新增手动诊断包预览与导出；更新检查默认没有地址，不会自行联网。

本版没有 Knorvia 账号登录，也不附赠模型额度。使用第三方模型或 CLI 前，需要用户自行确认其连接、认证、费用及条款。内核安装探测不代表已登录；中断后显示“结果未知”时应先核查再重试。

安装包未签名，Windows SmartScreen 可能显示提示。本轮未在真实模型、已登录 CLI、真实 SSH 服务器、真实更新服务或跨设备 Host 上做联调；创作服务的真实费用、取消行为和远端状态未验证。离线测试与本机模拟的通过不代表这些真实环境已经通过。

便携版更新时须先退出应用，只替换程序文件，保留 `data`。安装版卸载不应自动删除用户数据；用户若要彻底删除，应在确认备份需求后手动处理应用显示的数据目录。诊断包只会在用户手动预览、确认后写到本地，导出前应检查其中的日志摘要，确认可以分享。
