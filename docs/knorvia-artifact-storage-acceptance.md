批准的行为修复均先在旧公开接口、任务自有文件上复现：

- 历史附件协议能够被共享 URI 层识别，旧存储却因重复的当前协议判断拒绝读回。保留历史数据读/stat/派生兼容，新写入仍为当前协议。
- 会话名经过原有替换/截断后恰为 `.` 或 `..` 时，旧写入可离开配置的附件根目录。现在在 IO 前用明确错误拒绝；不改变普通名称规则，也不声称解决所有符号链接或 Windows 路径别名。
- 普通写请求在首次 await 期间被修改，会使旧文件内容、路径、MIME与返回 URI 不一致。新实现对用到的字段和二进制字节统一取调用时快照。
- 三个读取/stat回执也可能返回另一附件的 URI；ensure 的同 URI 共享 Promise 可能因首个请求被修改而返回另一 URI 的视频。新实现保持开始时的 URI/MIME，同时保留惰性调用实例公开 read 方法和精确 Promise 身份。

以上是公开边界的实际反例，不代表已证明所有应用调用者会发送这些输入。没有为修复静默改变取消、缓存有效期、磁盘布局或调用者协议。
