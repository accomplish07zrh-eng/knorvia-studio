## 5. 据此调整合同写法与包大小（已写回计划书）

1. **包大小按性质分档**：类型/声明为主可接近 60 继承文件上限；**运行时为主 ≤35–40 继承文件**，超大包在选包时按依赖重切（实证：core-tool-01 32 文件产 88 条 B/81 用例已很重；apps-cli-packages-01 因目录整体超限被迫事后重切 model/）。
2. **合同写法三条硬要求**：① 每文件在验收文档标注计分模式（普通/声明）与两道实测值，防声明模式藏实现；纯声明端口文件只能用声明模式，其中被剔除的运行时部分补包内单元测试。② 兼容声明块集中放声明文件，运行时文件不内嵌大段兼容声明。③ 注释全自己写——注释计入行相似度，`/**`、`*/`、`//` 等纯框架行会把包含率顶到 0.2–0.5。
3. **合同骨架固定**：README（版本+条目→测试对照表）、behavior（B 编号九项）、interface、callers、tests（公开入口、源码+dist 双入口）、fixtures、stubs、known-differences、acceptance、gate-old.json；旧门统一 `scripts/contract-gate.mjs`；**登记是最后一步**（旧门重跑会二次过期摘要）。
4. **桩互锁一律 C 通道**（ruling-stub-b88 先例）：删桩 + 桩镜像半边 oracle 改指 interface.md，断言强度不变，合同升版本重跑旧门，known-differences 登记。
5. **相似度计分**：normal/decl 两门都要跑、未过计数取并集；规则表类按公开事实重建（选择 9）；就地改写路径沿用既有登记、新路径登记 original，M6 全量复算口径覆盖。
