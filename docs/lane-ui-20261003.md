  分别有专用模块。遍历使用显式栈，deleted 行按父目录生成副本；不修改实际目录
  owner、数据、持久化 key、UI JSX、CSS 或资源。
- 待执行合同包含路径/UNC、Git 优先级、copy-on-write、错误引用、软链、压缩链、
  changedOnly/search 及深树场景。它们未在旧源或候选执行，不能称已冻结且通过。
- B1–B5 的历史实现和验证记录继续保留，不算本路成果，也不重写全局清单。
- 任务分组 `view.ts` 保留全部导出，位置 cursor、局部编辑事务和展示 selectors
  替换旧集中式编辑正文。拖拽目标在移除后重定位，菜单离组位置、归档只读过滤、
  workspaceIdentity、空组、no-op 及不受影响对象引用按先行契约保留。旧 hook/store
  继续拥有 optimistic 和 accepted 状态，`WorkspaceGroupedTasksSection` 未修改。
- 虚拟滚动以纯命令计划连接原 DOM owner，保持重新挂载时的旧零值屏障、显式
  滚动、横向和 behavior。虚拟列表组件和行高测量未修改。新增分组/滚动合同
  待统一执行；源码字节绑定见
  [任务分组记录](evidence/backlog-ui-20261003/grouped-task-projections.json)。
- 群任务进展 `groupProgress.ts` 通过当前 run/attempt 的 turn 索引和 pending
  interaction 关联派生任务/成员状态，以有序规则表达原状态优先级；成员按定义
  顺序映射。原 GroupProgressPanel、群编辑/发送/草稿 owner 与 checkpoint 格式
  保留。新 types 仅保留兼容 shape，不计独立作者结论。字节绑定及功能新增历史
  见 [群进展记录](evidence/backlog-ui-20261003/group-progress.json)。
- v4 列表以显式比较 frame 替换递归结构比较，并在同一身份/顺序下复用旧对象和
  数组。identity 委托现有 UI taskQueryCache 公共 helper；activity/membership、
  sessions-index store、grouped hook 和行组件未修改。新增待执行合同包括 getter
  顺序、sparse 数组、深层 metadata、重复身份、远端隔离及真实 activity/membership
  helper 组合。字节绑定见
  [v4 列表记录](evidence/backlog-ui-20261003/task-list-stabilization.json)。
- 文件树 watch 由逐路径请求票据和 owned subscription registry 管理。保留已安装
  watcher 的原回调、非递归路径粒度及折叠重开行为；服务切换/卸载的迟到结果由
  原服务释放。修复旧回包误清新 pending、订阅安装异常泄漏和过期 unwatch
  rejection；同步 dispose 异常仍抛出且其余 owned ids 会清理。JSX/事件协议
  未改。先行契约见
  [生命周期规格](../specs/knorvia-next-ui-file-tree-lifecycle-20261003.md)，字节绑定
  见 [watch 记录](evidence/backlog-ui-20261003/file-tree-watchers.json)。
- 搜索索引由一个 reducer snapshot 拥有 packed/loading/loaded/error；逐请求接受权
  处理 refresh、替代、禁用和卸载。保留已有成功索引的刷新/失败展示、分块 RPC、
  codec 和 worker requireQuery；修复 identity/remote-only reset 未重载和过期回包
  回写。没有新增 host abort 或修改索引数据格式。字节绑定见
  [搜索索引记录](evidence/backlog-ui-20261003/file-tree-search-index.json)。
- Sticky owner 对 expanded directory 建按 depth 的索引，再用二分前驱查询生成

  按数量收敛规则；原虚拟行/scrollTop/JSX/CSS 不改。字节绑定见
  [sticky 记录](evidence/backlog-ui-20261003/file-tree-sticky-folders.json)。
- 目录加载/刷新采用单一 snapshot owner、对象票据 ledger 和 cursor worker 调度；
  React 通过 useSyncExternalStore 读取同一份目录/expanded/loaded/loading/Git/
  ignored 状态。保留所有公开返回字段、Set updater/ref、silent 普通目录链预取、
  软链排除、watch 失败 subtree 裁剪/父目录重读、手工失败保留旧树、超时和刷新
  重入。scope cleanup 撤销所有接受权及 debounce；bulk flush 使用当前展开集合。
  gitStatus helper 仅把输入类型收窄为实际使用的 refresh port，原正文保留且不计
  独立实现。字节绑定见
  [目录加载记录](evidence/backlog-ui-20261003/file-tree-data-owner.json)。
- 分组 hook 的 remote 单飞缓存改为 epoch/demand 对象票据，并直接接入原 refresh。
  同 key 原 Promise、跨 key 最新 demand、invalidate 后迟到结果和 pending 清理
  保持契约；跨挂载 view 缓存仍最多 8 项且读不更新淘汰次序。原 scope key/
  Controller join/optimistic/mutation owner 本批保留，不把整个 hook 称已重写。
  先行规格见
  [分组生命周期](../specs/knorvia-next-ui-grouped-lifecycle-20261003.md)，字节绑定见
  [remote 缓存记录](evidence/backlog-ui-20261003/grouped-remote-cache.json)。
- 分组拖拽用单一 actor/target 分派替换七个目标 helper 的嵌套组合，直接接入
  原 DndKit section。header/footer direction、collapsed/empty zone、group over
  group/task、只看 type 的碰撞筛选和 order-only signature 保留；JSX、class、
  animation/overlay、Workbench、cancel/end rollback owner 均未改。目标投影
  不等于整个 drag 生命周期已重写。字节绑定见
  [拖拽路由记录](evidence/backlog-ui-20261003/grouped-drag-projection.json)。

  保留首屏 loading、最新请求单次日志、失败结束门禁与旧列表；明确修复 scope/

## 来源记录与界限

作者已读取当前文件树 model/search/refresh 及直接 hook 消费者，以当前行为提取
契约；也读取了任务分组、群进展、v4 稳定化原实现及相关消费者。因此本路是
**source-exposed**，不声明 clean-room。新算法按先行契约独立表达；公共类型、
简短接口表达、预览对象 shape 和既有依赖仍需完整作者/权利核验。

[文件树字节记录](evidence/backlog-ui-20261003/file-tree-projections.json)。这是对指定
文件的源码字节绑定，不是全量来源审计或行为验收。原全局 inventory 中 model
属于 upstream-modified/NOASSERTION，search/refresh 等分类继续保持其历史限定；
新字节未经整合者复核，不自动授 MIT。生产和本批待执行 tests 保留 Apache-2.0
过渡声明；根 LICENSE、NOTICE、第三方许可证、版权及依赖均未修改。
