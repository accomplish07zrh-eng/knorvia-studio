契约；也读取了任务分组、群进展、v4 稳定化原实现及相关消费者。因此本路是

属于 upstream-modified/NOASSERTION，search/refresh 等分类继续保持其历史限定；
新字节未经整合者复核，不自动授 MIT。生产和本批待执行 tests 保留 Apache-2.0
过渡声明；根 LICENSE、NOTICE、第三方许可证、版权及依赖均未修改。
