# Knorvia 进入动画

2026-09-27。用户要求为 Knorvia Studio 加一段精致的进入动画。范围是桌面主窗口启动；更新状态小窗、资源监控、CUA 浮窗与 Web 远控页不变。

## 编排

入场（启动壳，约 0.9 秒）：

1. 背景上一圈极淡的光晕由小到大展开。
2. Logo 从下方 10 px、0.9 倍、12 px 模糊浮现到清晰（0.72 s）。
3. 一道白色光泽斜向扫过 Logo，只落在 Logo 像素上（遮罩指向同一张图片）。
4. 视觉语言的三道笔画按深浅 100% / 55% / 24% 依次展开，K 斜度 -28°。
5. 字标「KNORVIA STUDIO」由宽字距、轻模糊收拢到 0.16em。

退场（React 首屏已提交且入场完成后）：

1. 启动壳 0.52 s 内淡出，内容轻微放大并虚化。
2. 公共工作面（`data-studio-workspace-sheet`）上浮 14 px、0.99 倍落位。
3. 窄工具栏按钮、内核按钮、底部操作依次从左侧滑入，间隔 36 ms。
4. 1.4 s 后移除 `knorvia-studio-entering` 与临时标记，之后挂载的元素不会再播放动画。

## 规则

- 仍然是双条件退场：入场动画结束（以字标 `animationend` 为准，1.4 s 兜底）且 `knorvia-react-startup-ready`（3 s 兜底）。主入口静态加载，不因动画推迟。
- 应用层只动 `opacity` 与 `transform`；模糊只用于小面积的 Logo 与字标。动画不使用 `forwards` 残留 transform，结束后不影响 `position: fixed` 与玻璃材质。
- 颜色随首屏主题：首屏脚本额外写入 `data-knorvia-startup-theme`，笔画与字标在深浅主题下分别使用黑白墨色。
- 系统减少动态效果：入场各元素直接显示为最终状态，启动壳 0.16 s 淡出，工作面与导航不播放动画。

## 验收

1. 深浅主题下截取 0.2 / 0.45 / 0.7 / 1.1 s 关键帧，Logo、笔画、字标依次出现且无颜色越界。
2. React 首屏慢于动画时停在完成态等待；快于动画时等动画完成后退场。
3. 更新状态窗口不显示启动壳。
4. 减少动态效果下无位移动画；测试覆盖相关 CSS 与退场条件。
