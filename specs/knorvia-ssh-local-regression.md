# SSH 功能本地模拟验收

更新：2026-09-25。延续 `knorvia-ssh-agents.md` 的真实连接实现；本轮只验证本机状态机和协议边界，不建立 SSH 网络连接。

## 产品规则与状态所有者

- 窗口 Host 的 `WindowRemoteConnectionRegistry` 独占连接、认证、工作区绑定和断连状态。测试使用注入的本地连接进程替身；只有在线且工作区身份、路径都匹配的会话可向 Studio 提供远端服务。连接事件中的凭据不得进入持久状态或 Agent ID。
- Studio Host 独占 Agent 目录、会话、群运行、停止和结果未知的记录。远端 Host 协议替身只响应 `inspectKernels`、`command`、`timeline`、工作区准备与变更，不触发任何真实 CLI 或 SSH。
- 探测只公布远端协议明确报告 `installed: true` 的外部内核；两个主机相同 CLI 和相同项目路径必须保留不同身份。断线后保留离线目录记录，但拒绝新派发；重连仅按稳定工作区身份恢复。
- 单聊始终使用绑定远端的绝对目录；群聊的跨机成员各走自己的服务和隔离目录，不把远端路径交给本机工作区文件操作。
- 发送请求一旦进入远端 RPC，断连或回执丢失都记为结果未知；停止必须发远端取消并以观察到的终态为准。未知任务不能自动重放，只有用户检查后以 `retryUncertain: true` 显式继续，且新尝试使用新的派发 ID。

## 事件顺序与验收

1. 本地连接替身建立窗口 logical session、绑定工作区；探测协议替身返回已安装、未安装与失败环境，核对目录和身份。
2. 本地单聊替身验证建会话、发送、时间线完成、工作区路径；群聊替身验证本机与两台远端成员的实际调度和独立路径。
3. 模拟连接关闭、旧会话离线、同身份新连接恢复、异身份或路径相同但身份不同不能顶替。
4. 模拟停止并确认取消回执；另模拟发送后链路故障，确认保留未知、阻断新发送与自动重放；显式确认重试后验证新尝试。

记录类型、Lint、架构及离线测试真实结果到 `docs/knorvia-stage2-acceptance.md`。真实 SSH 认证、远端进程部署、模型及跨设备行为均为“本轮不做远程测试，未验证”。
