# 视觉效果整体升级（2026-10-09）

用户要求「再全部升级一遍视觉效果，然后发布」。本轮只提升观感，不改布局与交互；全部限定在 Knorvia 明暗主题样式与共享组件边界，因此 Knorvia、外部内核、工作台、群聊、自动化、工作流、创作、插件与设置同时生效。只用黑白与透明度；系统开启「减少动态效果」时所有新增动画与位移停用。

## 变化

- 工作面纸片：顶部极淡内高光与柔和外投影，形成受光面（深色主题用更低的高光）。
- 活动栏：选中项为浮起纸片，左侧一道短指示条（出现时由短变长）；悬停时图标上浮 1px。工具区与内核区一致。
- 输入卡：静止时顶部内高光；悬停边缘略深；聚焦为发丝描边加柔和光晕。
- 主按钮：极轻纵向渐变与内高光，有厚度感；悬停浅色主题提亮、深色主题压暗。
- 发送按钮：可用时悬停轻微放大。
- 卡片：悬停时边缘加深并浮起柔和投影。
- 用户消息：由平面灰块改为纸片。
- 空会话问候：淡入（不做位移，避免入场期间布局几何变化），三道笔画依次画出。

## 实现

`packages/ui/src/styles.css`「⑥ 视觉升级」段落；活动栏按钮包在提示触发器中，`data-slot` 会被替换，因此选择器按 `button[aria-pressed]` 匹配。

## 验收

- 浅色／深色截图对比：活动栏指示条、输入卡高光与焦点光晕可见，其余页面无错位。
- 桌面 Electron 侧栏与布局冒烟、工作台冒烟、UI 测试、全量离线测试、typecheck、lint、fmt、架构与来源清单。

## 发布：Windows 安装器崩溃取证

0.11.3 发布时 Windows 安装版验收两次在首次静默安装即以 0xC0000005（-1073741819）退出，便携版与 Linux 均通过；此前 0.11.1 等也偶发同一退出码，重跑通过。已确认：崩溃发生在首次全新安装（不是覆盖安装或卸载）。待验证：崩溃阶段与故障模块。

- 原因无法定位：安装器阶段日志写在验收 fixture（TEMP）中，失败后随 fixture 删除，输出只剩退出码。
- 处理：`scripts/desktop-release-acceptance.mjs` 在安装失败时保留安装器阶段日志末尾 40 行与 Windows 应用程序日志中的崩溃记录（事件 1000/1001/1005，含故障模块），写入验收报告与标准输出。验收判据不变。
