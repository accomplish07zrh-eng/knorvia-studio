# core-03 兼容接口面（v1）

## 范围

35 个继承文件：`apps/cli/packages/core/src/workflow/**`（33）、`src/index.ts`（1）、`src/telemetry/**`（1）。

- **不属本包**：`src/environment.ts`、`src/output.ts`、`src/runtime.ts`（留给后续包，本包不改）；`workflow/scheduler/{graph,node-runner-outcome,ready-order}.ts` 为 `original`（本包不改）。
- 同样不碰：core-01（agent/compact/context/embedded-search/mcp）、core-02（memory/model/permission/plugin-reference/runtime-task/session\*）、试点 1（hooks）、subagent/system-reminder 等。

## 黑盒入口

- 主入口：**包根** `src/index.ts`（源码入口 tsx 下已可加载，`import` 得 190 个具名导出；两处「类型当值再导出」已修，见 `known-differences.md`）。
- 区域桶（分块测试用）：`workflow/expert.ts`、`workflow/scheduler.ts`、`workflow/lifecycle.ts`、`workflow/definition.ts`；`telemetry/` 只有一个模块（`runtime-telemetry.ts`），无桶。
- `workflow/scheduler/graph.ts` 与包根各含 `export *`，其导出已在本表**展开为具名清单**。
