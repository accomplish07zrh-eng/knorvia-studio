# 工作台易用性第二轮：新建任务、紧凑顶栏、两行八格与缩放

2026-10-08。延续 `knorvia-task-workbench-20261008.md` 与 `knorvia-workbench-artifact-preview-20261008.md`。用户在 0.11.0 实机反馈：

1. 添加任务不便：要把已有格子全部收起后才能新建，再逐个恢复。
2. 顶部「每格独立输入、审批和停止」说明行与「汇总进行中任务」工具行、已收起面板占用过多高度，格子显得矮。
3. 小窗口下界面要处理好。
4. 放格子的主要区域要能缩放。
5. 容量改为最多上下两行、每行最多四格（上四下四，共八格）。

本项替代旧规格中「最多四格」的容量与常驻说明行，其余规则（收起不停止任务、汇总只填余位、64 个收起上限、身份与连接归属）不变。

## 产品规则

### 新建任务

- 顶栏常驻「新建任务」。点击后：
  - 已有未经配置的待命格 → 聚焦该格，不再新增；
  - 否则在容量与两行四列约束内自动选位新增待命格（见「自动选位」），新格沿用当前聚焦格的内核与项目，用户可直接「开始输入」或改选；
  - 已满八格 → 当前聚焦格收起（任务继续、草稿保留，可从「已收起」恢复），在原位置放入新待命格。按钮提示说明此行为。
- 每格「⋯」菜单提供「在此格新建任务」：本格已开始的会话收起进「已收起」，原位置换成同内核、同项目的新待命格；未动过的待命格直接保留。
- 新建只改布局引用，不发送 create/send/resume/approval/cancel。

### 紧凑顶栏

- 原说明行与工具行合并为一行：新建任务、汇总进行中任务、任务列表、已收起、缩放控件、格数 `n / 8`。原说明文字改为说明图标的悬停/读屏提示。
- 任务列表与已收起改为顶栏下方的浮层，展开时覆盖在格子上方，不再挤压格子高度；按 Esc 或再次点击按钮收起。来源离线、收起已满等提示显示在相应浮层内。
- 顶栏窄于 720px 时按钮只显示图标（保留完整无障碍名称与悬停提示），并允许横向滚动，不换行撑高。

### 两行八格

- 布局约束：任意布局的「行数」≤ 2、「列数」≤ 4，格数 ≤ 8。行列数按分割树计算：叶子为 1×1；左右分割行数取两侧较大值、列数相加；上下分割行数相加、列数取较大值。
- 左右/上下分格按钮在结果超出约束时禁用；持久化布局解码时同样校验，超出约束的旧数据按无效处理并回到默认布局。
- 自动选位（新建任务、汇总、加入工作台）：在所有满足约束的「叶子 × 方向」候选中，选面积最大的格子；同面积优先沿该格较长边分割（按 16:9 画布估算），再优先聚焦格。依次得到 1 → 左右 2 → 2×2 → 2×4 的均衡网格。
- 常规聊天区的分屏（`MAX_WORKBENCH_PANES = 4`）不受影响；工作台以显式上限 8 调用同一纯布局函数。

### 小窗口

- 格子标题栏按自身宽度自适应（容器查询）：宽格显示「左右」「上下」文字按钮；窄格只保留标题、视图切换、放大和收起图标，分格与「在此格新建任务」进入「⋯」菜单。标题始终可截断，按钮不溢出。
- 格子最小尺寸仍为 360×300 CSS 像素，随画布缩放同比缩小显示；画布不足时滚动。

### 画布缩放

- 顶栏缩放控件：缩小、当前比例（点击复位 100%）、放大；范围 50%–150%，步长 10%。缩放作用于整个格子画布（含格内聊天与预览），不改变分割比例。
- 缩放值随布局持久化；非法或缺失值按 100%。
- 缩小后同一窗口可容纳更多格的最小尺寸，配合两行八格使用。

## 状态所有者

| 状态                   | 唯一所有者                                     | 说明                                    |
| ---------------------- | ---------------------------------------------- | --------------------------------------- |
| 布局、格子、收起、缩放 | 工作台 store（`TaskWorkbenchState`）           | `zoom` 新增字段，`decodeWorkbench` 校验 |
| 行列约束与自动选位     | `workbenchModel` / `workbenchPlacement` 纯函数 | 不读取 DOM                              |
| 浮层展开、菜单开合     | 组件局部状态                                   | 不持久化                                |

```text
新建任务 → store.create()
  ├─ 有未配置待命格 → focus(该格)
  ├─ autoSplit(board) 成功 → save(新布局, 新待命格聚焦)
  └─ 已满 → 聚焦格入收起（≤64）→ 原位放新待命格 → save
在此格新建 → store.renew(pane, expectedId) → 旧格入收起（若已动过）→ 原位新待命格 → save
```

## 验收

- 三格时点「新建任务」直接得到第四格，无需收起；八格满时新建会把聚焦格收起并可恢复。
- 「在此格新建任务」收起原会话、保留草稿与身份，原位出现同内核同项目的待命格。
- 约束：1→8 次自动新增得到 2×4；任何操作都不能出现第三行或一行第五格；超出约束的持久化布局被拒绝。
- 顶栏单行；浮层不改变画布高度；窄窗口顶栏不换行、格子标题栏不溢出。
- 缩放 50%–150% 生效并持久化，分隔条拖动在缩放下仍按指针位置换算。
- typecheck、lint、fmt、架构、来源清单、针对性测试与 Chromium 工作台冒烟。
