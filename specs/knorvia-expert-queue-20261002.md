# Remaining expert workflow owners

Complete coherent batches in workflow/expert only: runtime commands/manual retry;
parser normalization; scheduled-phase/failure delivery; prompt/status rendering.
Preserve existing phase, critic, context, graph-artifact and continuation candidates.
E's workflow/scheduler source is excluded. No cross-lane source adoption or merge.

Each batch retains exact historical source/JS/declaration, functional/API-only packet,
fresh draft hashes before source comparison, and candid expression evidence. Native
await gates, registration/finally, projection identity/order, parser schema/fallback,
UI/model text and port receiver/error boundaries are fixed. No novelty requirement.
Ordinary tests/builds are skipped; only a concrete discovered defect warrants minimal
synthetic data/publication proof. Scoped type/API/format checks can detect draft errors.
Current emitted generation is deferred unless that proof requires it. Historical
artifacts cannot be relabeled current. Commit/push/report each batch, then continue.

One registry/context owns runtime resources; lifecycle helpers own graph repairs;
parsers own normalization; rendering owns text with fixed inherited prose. No second
state owner, generic framework or retry/cancellation policy. Declarations/types and
constrained naming/status/sanitization helpers (types.ts, ids.ts) stay unchanged,
with hashes and rationale recorded. Their preservation earns no reconstruction credit.
No header/global licence/inventory or environment/settings changes.
