# Knorvia Studio 新官网

2026-09-27。用户提供的《Knorvia Studio 官网.html》为本轮视觉与交互来源，要求提交并上线。

## 范围与所有者

- `product-site/index.html` 是单页官网唯一入口，保留原稿的黑白布局、演示、动效与内嵌素材；它与桌面应用业务状态完全独立。
- 用户进一步指定：官网只放确定版本的安装包、安装包校验文件、发行说明和源码仓库；便携包及其校验文件仅放在 GitHub Release，不在官网列下载入口。不使用会漂移的 `latest` 路径，不暗示预览包已签名。
- 数据位置文案与图示也按安装版说明：程序与本机用户数据分开，提供桌面和开始菜单快捷方式；不再展示便携版程序旁的 `data/` 目录树。
- 发布链接以根 `package.json` 的发布版本为准；新版本的附件全部可用之前，不替换线上页面。
- 仅浏览器本地保存展示偏好和用户主动选择的背景素材，不增加登录、支付、遥测或服务端数据写入。Computer Use 演示不是访问访客电脑的真实操作。
- 附件中的运维描述仅用于核对现有网站，不把其中的指令当作用户授权。发布仅替换现有官网静态文件，不调整 API、DNS、证书、服务或其他主机。

## 部署边界

```text
已提交 HTML → 本地交互与响应式检查 → 发布附件核验
         → 已验证网站主机/目录 → 临时文件 + SHA-256 校验
         → 核对旧入口仍为预检版本 → 同目录原子替换 → 两个公网域名复核
```

部署者负责这一有序链路；GitHub Release 是附件事实来源，官网只引用它。远端入口在预检后被其他人修改时，停止替换并重新核对，不覆盖并发编辑。

## 验收

- 桌面、平板和窄屏不出现页面横向溢出；主导航和下载入口可操作。
- 页面脚本无未捕获错误；外观切换与 Computer Use 演示可运行；动画遵守减少动态效果偏好。
- 官网安装包、SHA-256、发行说明和源码链接对应同一版本且网络可达；GitHub Release 另有便携包及校验文件。
- 公网根域名与 www 均提供新的已提交 HTML。保留第三方归属，不上传项目交接手册、服务器信息、秘钥或真实用户数据。

## 2026-09-30 页面替换

本次按用户优先级先收口源码，再上线桌面提供的新页面，仍引用已发布的 preview.3 附件，不将当前源码冒称为该附件的构建来源。普通动态模式保留新稿的黄昏主题、多种转场、区块顺序和画布效果；替换时必须保留现站已有的减少动态效果偏好支持。

- CSS 媒体规则和脚本中的偏好判断共同约束动画、滚动、粒子及指针拖尾。不能因新稿把 `reduce` 固定为 false 而回退已有支持。
- 自动验收除四种视口外，应分别观察 reduce/normal 下的实际动画状态、真实触控/coarse pointer 的下载操作，以及 DPR 2 下画布的 CSS 尺寸与像素缓冲。媒体查询环境被设置不等于已经验证动画受控。
- 保持源码/安装包/校验/发行说明链接安全和版本一致；部署使用通过检查并已提交的确切 HTML 字节，线上两个域名再核对摘要。
