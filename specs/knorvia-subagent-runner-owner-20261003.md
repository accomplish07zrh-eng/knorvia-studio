## Single ownership and native gates

One port captures registry (option or fresh InMemoryRuntimeTaskRegistry), normalizes profiles once with supplied built-in overrides, and normalizes autoBackgroundMs once: finite positive number -> truncation, including positive fractional becoming zero; otherwise undefined. One private per-port abort-controller identity table and foreground-model-borrow set; no additional queues/caches/retries/notifications. Registry remains authoritative for tasks/messages/background/notified state. Methods are native async. getTask returns registry.get; waitForTask returns registry.waitForTerminal(id,{signal}); backgroundTask for borrowed model returns current task without requesting background, otherwise requests background then reads. Preserve receivers on options and registry calls. Optional logger methods retain optional call semantics.

Launch resolves profile/type before admission. Explicit runInBackground===true OR profile.background===true requests background. If that route and modelOverride.background==='deny', reject ToolExecutionFailed with exact idle-time message in runtime-text, context code BACKGROUND_UNAVAILABLE,agentType raw request,parentToolCallId,recoverable true; no task/artifact/child effects. Otherwise background launch invokes current port.start with runInBackground property removed, options object signal present even undefined and truthy model only. Foreground launch invokes current port.run with same execution request and original launch options. Canonical matching described below must apply in all entry methods. Methods call the returned port, not stale captured aliases.

Run lifecycle:
1. Resolve profile/canonical request, create identity/path/traces and started Date; register running foreground snapshot. Await initial metadata write. If that rejects, remove task and rethrow original; child/abort/watchdog not started.
2. Create task AbortController, store by agentId, link parent signal: pre-aborted forwards reason nullish fallback Error('Subagent task aborted: ID'); otherwise add once listener. Detach removes listener; dispose detaches then deletes table entry only if controller identity still matches. Record borrowed agent when modelOverride !== undefined (not truthiness). Install foreground inactivity watchdog, start immediately before invoking child, covering readiness/setup as well as execution.
3. Start child-completion operation without awaiting immediately. Child options fresh object signal, conditional truthy model,conditional truthy modelOverride. ReportActivity supplied. Native async readiness callback first awaits SubagentSpawned event then resolves single native promise gate. Spawn payload order agentId,agentType,childSessionId,description,prompt,parentToolCallId,status='running',allowedTools fresh array,model present (profile provider/model joined slash or undefined). Attach child failure -> readiness reject without swallowing later child result. Await abort-guarded readiness; rejection stops watchdog,aborts child with error,disposes,deletes borrow,removes task,rethrows. No terminal artifacts/outcome after this setup failure.
4. Log spawned. Guard child completion by same signal. Set up auto-background timer and native registry background-request wait only when not borrowed; timeout additionally requires normalized value !==undefined. Race completion tagged completed, optional request result backgrounded/ignored, optional timer result backgrounded/ignored, in that input order. Ignored race result still awaits guarded completion. Timer/registry failure flows through ordinary failure catch, not new recovery.
5. Background winner: detach parent,stop watchdog; attach child completion -> background completion -> failure finalization -> finally abort dispose, WITHOUT waiting for this continuation. Return async_launched output; public finally stops watchdog and cancels timer. Child continues owning original identity. Do not abort on parent cancellation after detach.
6. Foreground completion: cancel timer,stop watchdog,dispose,delete borrow BEFORE artifacts; await completed artifacts,update registry terminal snapshot stripping messageSink/pendingMessages,then await SubagentStopped completed event,log and return the exact completed output reference. Event fields agentId,agentType,childSessionId,parentToolCallId,status,totalDurationMs,totalToolUseCount,totalTokens (present even undefined). Registry terminal fields ordered after retained snapshot: status,completedAt Date,output same reference,usage {durationMs,modelUsage,toolUseCount,totalTokens}, with undefined fields retained.
7. Ordinary failure catch starts by stop,dispose,delete borrow; capture Date.now-start/error.message or String; await failed artifacts; update task failed stripping message state (status,completedAt,error,usage durationMs); await stopped event fields agentId,agentType,childSessionId,parentToolCallId,status failed,totalDurationMs,error. CoreError rethrown identity; other error wrapped ToolExecutionFailed/'Explore subagent failed',cause only Error,context withErrorPayloadRole({code CHILD_RUNTIME_FAILED,agentId,agentType,parentToolCallId},Wrapper),recoverable true. Publication failures within this catch override original naturally. Native finally stop watchdog/cancel timer, including both branches.

Start lifecycle: resolve/create identity/build background output;register background running task;await initial metadata and remove/rethrow on failure. Create unlinked child controller; only pre-aborted start signal forwards its reason, no later parent subscription. Start native background worker without await, child options signal plus truthy model; readiness callback awaits spawned event before resolves. Spawn order agentId,agentType,background true,childSessionId,description,prompt,parentToolCallId,status running,allowedTools copy,outputFile,model (present undefined). Await readiness promise without foreground abort guard/watchdog. Failure aborts and removes/rethrows; success logs and returns previously built output. Background worker always calls dispose finally. Do not add signal checks, timeout or cancelled-state repair to this route.

Background worker: at entry read task (missing treated terminal lost) and asynchronously return no-op if terminal. Otherwise await child operation. Its native readiness callback awaits the caller readiness callback, THEN marks ready true. Completion awaits background finalization. Failure before readiness invokes optional setup-failure callback and returns (no terminal artifacts); after readiness awaits background failure finalization. Finally synchronous optional onSettled, even no-op. Keep native async/no-op await boundaries: don't inline these promises into a different settlement policy.

## Cancellation/timers/messages

Watchdog disabled for nonfinite/nonpositive timeout; three no-op methods. Active clock initialized on construction then start/reportActivity reads Date.now and resets timer; stop clears timer and assigns undefined; scheduling stops first and skips aborted signal. Fired timer computes idleMs,ToolTimeout 'Subagent was inactive for TIMEOUTms',context code CHILD_RUNTIME_FAILED,agentId,agentType,idleMs,parentToolCallId,timeoutMs,recoverable/retryable true; logs then abort(error). Default DEFAULT_MODEL_STREAM_IDLE_TIMEOUT_MS uses nullish fallback. Existing OS timer semantics only; no new deadlines/background watchdog.

Abort guard: when signal absent return original promise identity. Otherwise native Promise subscribes completion before checking signal/add listener; settles once, removes listener BEFORE resolving/rejecting. Already-aborted CoreError reason rethrown reference,else ToolCancelled exact message from runtime-text,cause only Error,context code/agentId/agentType/parentToolCallId,recoverable true. No post-add aborted recheck. Auto timer promise similarly once-only,clears timer/removeslistener before resolve; preabort returns ignored; timer registry.requestBackground result -> backgrounded/ignored; cancel ignored; normalize delay rule above preserved.

Message admission: preabort returns failed result, no registry read; else registry.get(to),missing/nonlocal -> failed. Failure result status failed,messageId new msg_UUID,agentId=request.to,error,message=same error, ordered. Create native pending message once: id,msg; isMeta true;message;origin {kind coordinator,toolCallId:String(parentToolCallId)};queuedAt Date;summary;traceContext request.trace. Running/nonterminal with sink awaits sink.send on sink receiver,then success; rejection queues same message and returns queued; no sink queues then returns queued. Queue boolean not converted to failed. Success ordered status,messageId,delivery,agentId,taskId,outputFile (present undefined),message. Exact queued/resumed/sent prose retained in runtime-text.

Terminal message resume: exact stored profile name lookup only; missing profile/missing child session returns failure without task replacement. Resume request order sessionId,turnId,parentToolCallId,agentType stored,description=summary||old description,prompt message,workingDirectory,workspaceRoot,trace. Store exact previousTask reference,register new running background snapshot,await metadata with resumedAt ISO,resumedFromMessageId extras. Write failure restores previous exact snapshot and rethrows. New unlinked controller; background worker resumeFromStore true. Ready callback awaits spawned event payload order agentId,agentType,background true,childSessionId,description,outputFile,parentToolCallId,prompt,resumed true,status running (no tools/model). Readiness failure aborts,restores previous snapshot,rethrows; success provider result uses old task status/identity with new lifecycle outputFile and delivery resumed_background.
