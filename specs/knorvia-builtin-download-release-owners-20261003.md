# Built-in download and release owners

The download call is the sole owner of one total twenty-second timeout, caller cancellation, two sequential credential-free redirect-rejecting requests, bounded streaming reads and sanitized stage errors. It does not own cache, endpoint identity selection, subscriptions or persistence.

Input → timeout/caller signal → client configuration → optional HTTPS release URL → streamed release JSON → canonical release decoder. No URL means null. Every body is bounded at ten million bytes; late responses are cancelled after abort and reader cancellation is fire-and-forget with lock release. Request receiver and response-promise admission order remain compatible. No retry, new endpoint or security policy.

The synchronous release codec owns strict schema admission, retired-provider rejection, preserved parser-result identity and shallow freezing. Provider and template identities are captured before checking retirement; revision precedes model parse; serializers preserve method receivers and compact output. Canonical schemas, field names, error strings and conventional abort bridge are retained expressions, not originality evidence.

Complete candidates were frozen before deliberate source-body comparison; this spec precedes installation. Source-exposed correction preserves malformed URL refinement throwing as sanitized invalid response, signal ordering, late-response microtask boundary and template capture timing. The packet generalization that all malformed URLs yield schema errors is not authoritative for the baseline quirk.

Minimum fake request/reader/timer/parser checks use actual Zod and in-memory cancellation only. No real network, user data, account, file, permission or migration operations. Target-rooted type/API and static checks do not replace deferred full integration, builds, native behavior or independent-expression/rights acceptance.
