# 单聊一致性、强度条与界面质感（2026-10-08）

用户在 0.11.1 实机反馈并确认：

1. Knorvia 与其他内核的单聊界面不一致：侧栏列表结构、行样式与操作不同；输入框发送按钮外观不同；Knorvia 工作台格子缺少输入框下方的项目行。权限按钮内容不同属正常（各内核权限不同），只统一样式与位置。
2. 定时任务页：「创建定时任务」拼接按钮错位，「保持电脑唤醒」开关看不出开关。
3. 思考强度条：Grok 档位反向；外观要像 Codex，但更好：未到能选的最高档时填充为白色，到达最高档时变成黑白渐变并带「喷射」动效；各内核、各模型最高档不同；不放进模型选择器。
4. 整体界面与 UI 提升一个档次（仍遵守黑白视觉语言）。

## 规则

### 侧栏单聊列表

- 外部内核侧栏只列 Host 已受理的会话；未发送草稿不再列出。
- 未发送草稿继续保存在草稿存储中；从其他内核切换到某外部内核时，打开该内核最近更新且仍有正文或图片的草稿（`latestStudioKernelDraftId`），没有时才新建空白会话。点「新建任务」仍新建空白会话。
- 行样式与 Knorvia 任务行同一配方：顶部「单聊列表」小标题；按项目分组，组标题为侧栏分区标题的灰字；单行圆角、选中为纸片、悬停高亮；标题单行截断，右侧相对时间（与 Knorvia 相同格式），悬停或聚焦时时间让位给删除按钮。删除确认、Host 删除命令与删除后导航不变。

### 输入框

- 外部内核发送按钮与 Knorvia 同一外观：圆形、前景色；不可发送时为中性灰，不再在空输入时显示为可点的黑色。
- Knorvia 工作台格子在输入框下方显示本格项目（只读：格子打开后项目已固定），与外部内核格一致。

### 定时任务页

- 拼接按钮外层声明 `data-slot="button-group"`，两半直角拼接、外层统一为胶囊，下拉半边带细分隔线；编辑器打开按钮组同样声明分组。
- 自动化开关：关闭为浅灰轨道加白色滑钮，开启为前景色轨道加背景色滑钮，明暗主题都能区分开关。

### 思考强度条

- 档位按强弱从低到高排列：每个档位都能识别强弱时按强度稳定排序（修复 Grok「极高→低」上报导致的反向），含未知档位名时保留内核顺序。
- 外观：单条圆角轨道与圆形滑钮，上方标题「推理强度」与当前档位名，下方为淡色档位名。未到本模型最高档时填充为白色；到达最高档（列表最后一档，因模型而异）时填充为背景色到前景色的黑白渐变，缓慢流动，并有两层错速光点向右划过形成喷射拖尾，滑钮带一圈柔光。系统开启「减少动态效果」时停用动画。
- 仍为输入框上的独立按钮，不并入模型选择器；存储、发送与校验不变。

### 界面质感

在黑白视觉语言内提升质感，只改共享组件边界与主题样式：

- 浮层（下拉菜单、右键菜单、弹出框、选择器、悬停卡）：更大圆角、发丝边、分层柔和投影、轻微磨砂半透明底，展开时短促的位移与缩放淡入；菜单行圆角高亮与过渡。
- 对话框更大圆角与浮层投影，遮罩轻微模糊；提示气泡圆角与投影。
- 文字平滑渲染。减少动态效果时取消浮层展开动画。

## 验收

- 外部内核侧栏无未发送草稿；切到 Codex 时输入框恢复上次未发送内容；行样式与 Knorvia 一致（截图对比）。
- 强度条：Grok 档位从低到高；非最高档白色填充，最高档黑白渐变动效；每个模型以自身最高档为准。
- 定时任务页拼接按钮与开关显示正常（明暗主题）。
- typecheck、lint、fmt、架构、来源清单、UI 测试、工作台与 Electron 侧栏冒烟。
