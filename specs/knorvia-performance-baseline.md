# 长会话与便携版性能基线

更新：2026-09-25。延续 `knorvia-backend.md`、`knorvia-polish-chat-pass2.md` 和现有 V4 时间线实现。

## 产品规则与状态所有者

- 原生 V4 聊天保留既有按 turn 虚拟渲染。Studio Runtime 继续独占外部单聊与群聊的持久消息、分页和运行状态；Studio 时间线仅负责可见行渲染、滚动位置和翻页交互，不截断、重排或自行持久化消息。
- Studio 长会话按消息稳定 ID 建立虚拟行，动态测量工具、推理、Markdown 与普通文本的高度。只挂载视口附近的行；键与滚动补偿不能依赖会变化的数组下标。
- 顶部加载旧页时保持用户正在阅读的消息和局部偏移；尾部新消息仅在用户跟随底部时吸底。向上阅读、流式文字增长、会话切换和回到底部都不得意外夺取滚动权。审批、运行历史和错误仍保留在时间线下方。
- 性能脚本使用本地隔离配置和合成 10,000 消息，不调用模型、CLI 或远端服务。统计滚动帧间隔、挂载行数、冷启动到窗口可交互时间、常驻进程内存与便携包字节；测量条件、命令和结果写入 `docs/perf-baseline.md`。若只能测到部分指标，明确写未验证，不能把模拟值冒充真实用户资料或远程场景。
- 打包使用 `KNORVIA_ENV=production`。覆盖桌面便携版前确认其进程未运行，排除 `data`，覆盖前后逐文件散列一致；如不一致立即停止。

## 事件顺序与验收

1. 将 Studio 最新页与旧页合并后的有序消息交给虚拟器；滚动时只挂载视口及少量预取行。
2. 用户请求旧页时记录可见锚点；旧页提交后按同一消息 ID 恢复视口偏移。用户在请求中继续滚动时更新锚点。
3. 新消息或动态行增高时，仅跟随底部的视口滚到底；离底阅读位置保持。显式“回到最新”重新跟随。
4. 用 10,000 条合成消息测量滚动并断言挂载行数有界；基线脚本记录环境、样本、统计口径及失败条件。原生 V4 既有虚拟列表做回归检查。

## T10 补充：运行历史有界渲染与桌面启动分阶段测量

更新：2026-09-25，HEAD `c763651`，版本 `0.8.0-preview.2`。只补充规则，不改变上文的时间线虚拟化、翻页锚点与便携交付要求。

### 产品规则与状态所有者

- 运行历史（成组细节面板、工作流历史面板）必须**有界渲染**：首屏只渲染最新一页窗口，其余按“显示更早运行”显式展开。窗口只是渲染层的只读派生（纯函数），运行历史的条数、顺序、`run.checkpoint.steps` 的读取口径与可执行操作都不因此改变；Studio Runtime 仍独占运行记录。
- 无论窗口如何，以下运行必须保持渲染：正在复核的运行（复核弹窗读取它的步骤结论），以及仍处于 `queued`/`running`/`waiting` 的运行（否则用户失去停止入口）。窗口始终是时间倒序的**连续前缀**，不允许跳号或重排。
- 时间线底部的 `compact` 运行历史保持既有行为（只显示最近 3 条，不提供分页）。
- 桌面启动必须可按阶段归因：进程启动 / main 模块求值 / app ready / 主窗口 loadURL / renderer 加载 / 首次 commit / Host 派生 / 首次可交互 / 可发送。测量只读取应用既有的 launch marks（`createdAt`/`mainStart`/`appReady`/`loadUrl`）、renderer 标记与进程表创建时间，不新增生产埋点、不改变既有 JSON 键。
- 冷启动与热启动必须分别记录：冷启动 = 全新隔离配置；热启动 = 复用同一配置目录。两者不可混在一个数字里。
- 生产日志不得记录高频原始流或敏感内容；启动期日志必须记录字节量与内容口径，作为回归项。
- 测量条件（机器、OS 构建、Node 版本、构建模式、数据规模、冷/热、样本数、命令）必须与实际执行一致；条件不同时只能声明“不可直接比较”，不能声明回归或改进。

### 事件顺序与验收

1. 服务端投影给出时间倒序的运行数组（最近 100 条 + 未决运行）→ 纯函数窗口取前缀 → 渲染。
2. 用户点击“显示更早运行”每次多渲染一页；重复点击后**全部**历史运行与步骤行都能重新出现（不丢条、不重排）。
3. 新增运行把旧运行挤出首屏窗口时，正在复核的运行与活动运行的渲染不受影响。
4. 启动测量脚本在既有 JSON 上只新增字段：`desktop.samples[].phases`、`desktop.firstInteractiveMs`、`desktop.hostStartup`、`desktop.readyToSend`、`runHistory`；旧键 `coldStartToOnboardingMs`、`idle`、`portable`、`scroll` 语义不变。
