# 显式内核接力与会话 Markdown 导出（T2.4）

2026-09-25。沿用现有 Knorvia 单聊与 Studio 外部单聊的状态所有者，不复制原生会话、私有记忆或内核配置。此项只实现用户主动发起的跨内核上下文转交和本地文件导出，不增加自动路由或新的聊天运行时。

## 产品规则

- 有内容的单聊提供“交给其他内核”和“导出 Markdown”。接力先从已在界面加载的当前会话消息生成**可编辑草稿摘要**，明确显示来源与截取范围；只取用户/助手可见正文及工具调用名称和状态，不收集推理、工具原始输出、隐藏提示词、MCP 凭据或原生记忆。摘要经过现有凭据形态脱敏；用户可修改全文，最终发送的是确认时编辑框中的文本。
- 目标必须与来源内核不同、当前可用，沿用来源项目。目标为本机 Studio 外部内核时新建独立 Studio 会话，确认后把摘要作为第一条消息提交；取消、关闭或修改目标之前，不调用目标内核或创建会话。未安装、未连接、目标项目无效、摘要为空或超长时明确禁用。原生 Knorvia 的 V4 会话由独立 owner 管理，本轮不把外部会话伪装成原生 Knorvia 会话；该目标须经 V4 新建及发送路径另行接入。
- 导出按会话持久时间线读取完整分页历史，最多 10,000 条消息或 V4 行及 8 MiB；超限或读取失败则明确失败，不静默导出不完整历史。原生会话使用 V4 `rows/range`，导出期间日志代际或修订变化则要求重试；外部会话使用 Studio Runtime `timeline`。只保留 realUser/assistant 可见文本与工具调用名称、状态的摘要；排除合成用户行、推理、工具原始输出和凭据形态。文件名由可见会话标题生成，先经过安全文件名约束；保存复用 `IPlatformService.saveFile`，Web 回退 Blob 下载。
- 接力和导出绝不调用真实模型生成摘要。摘要是本地提取草稿，不能冒称模型理解了完整会话。用户可以在确认框查看并编辑。真实目标内核的首轮执行属于外部服务行为，本轮仅用本地替身验证；不运行已登录 CLI、不发付费请求。

## 状态所有权与事件顺序

正式消息、会话定义和目标运行由 Studio Runtime 或原生 V4 owner 分别持有。UI 只持有当前打开的摘要草稿、选择目标和保存按钮忙碌状态；退出弹窗即丢弃未提交草稿。相同接力尝试使用一次生成的目标会话 ID，`create-conversation` 与 `send` 各有固定 commandId；网络回执丢失后重试同一命令，不能新建第二个目标会话或重复首条消息。创建成功而发送失败时保留目标 ID 和错误，用户可重试或取消，不能显示为已接力成功。

```text
已加载来源时间线 → 本地提取/脱敏 → 用户编辑与选择目标 → 明确确认
                                                       ↓
                                         Studio Runtime 事务创建新会话
                                                       ↓
                                          同一目标的首条 send 命令
                                                       ↓
                                       ACK 后导航到目标；运行结果仍看时间线

导出点击 → 分页读取来源持久时间线 → 脱敏并格式化 → 平台保存文件
```

会话切换、服务替换、项目变化或弹窗关闭使旧异步结果失去当前界面归属；迟到回执不得切到别的会话。确认前的摘要预览不发任何模型/网络请求。导出只属于用户指定的本地文件，不写进另一个会话，也不发送给远端。

## 验收

1. 本地替身验证摘要来源、确认前零命令、同一内核拒绝、失败重试使用固定 ID。界面层的取消与迟到回执守卫由状态测试另行覆盖，不把纯函数测试当成界面验收。
2. 导出测试覆盖 Studio 和 V4 历史分页、时序、工具摘要、凭据脱敏、大小上限和分页停滞；保存取消与真实文件对话框未经自动化验证。
3. 实际运行根 typecheck、lint、architecture:check --changed 和离线回归，记录真实结果。真实外部模型/SSH/付费调用与人工目视复核不作为本轮测试。
