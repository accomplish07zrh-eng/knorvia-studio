# project-brief

An example Knorvia Studio plugin containing one portable skill. It asks the active
agent to read an explicitly selected local project and write a short handoff
brief with file references. It runs no scripts, hooks, commands or MCP servers.

The package is a teaching example, not a ninth built-in plugin. Validate it
with the bundled plugin-creator before adding its parent directory as a local
source in Settings → Plugins. Installation and enablement are separate steps.

See `docs/knorvia-plugin-developer-guide.md` in the Knorvia Studio repository
for the full ten-minute exercise and the cross-kernel limits. When adapting
the example, replace its name, description, author and license with the terms
that apply to your own work.
