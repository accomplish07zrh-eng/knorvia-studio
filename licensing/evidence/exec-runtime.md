# 命令执行适配器独立实现依据

本批范围为 `apps/cli/packages/adapters/src/exec` 的 24 文件及新增的 25 份运行测试、支撑和入口文件。独立规格准备者阅读冻结旧实现，源码作者只收到批准行为、有限公共声明和保留依赖政策；先写所有权与状态设计，再写并冻结完整候选。独立测试作者未读候选，验收者先对旧版建立受控基线，再打开候选。目录隔离不是 OS sandbox，也不代表全线程 clean-room 或完整法律结论。

原候选由 GPT-5.6 Sol / xhigh 编写，首稿、修订和各次静态失败均保留。两处行为差异由原作者修复；根代理随后亲自修复普通输出限额结果投影。根在该修复前已读候选的输出、运行、状态和协调器实现，以及公开测试结果；未阅读旧 exec 私有体来实施此次修复。根另为模型合同准备阅读过两个旧 model 文件，属另一条工作流，未作为执行实现输入。公共签名、标准 API、通过测试与 MIT 头均不单独构成原创证明。
