# Complete StartupDiskSampler public behavior

Use ports/disk.d.ts and shared.d.ts. One sampler owns its logical entries, sealing and sampling/interval lifetime. No private names/decomposition required. Construction captures options.probe ?? default probe ONCE; onSample remains live via original options object. Probe calls are bound to the sampler instance (method-shaped property), callback bound to options. No validation/coercion of injected outputs. Preserve JS evaluation/error/receiver/reference behavior. Imports are Node stat/statfs promises, dirname, createHash and type-only shared summary.

## Default probe contract (all production IO remains through original imports)

Each default probe has a successful-location cache keyed by exact input path. On cache miss begin with dirname(input), never stat input itself; call stat(parent,{bigint:true}), catch only error.code exact ENOENT and only if dirname(parent)!==parent. On that condition reread dirname(parent) to advance and repeat; otherwise rethrow identical error. Successful stat gives path=parent and scope=createHash('sha256').update(String(info.dev)).digest('hex'); cache it before statfs so later statfs failure retains cached location. No promise-sharing or failures cached, no directory reads/realpath. Every probe calls statfs(cachedParent,{bigint:true}), multiply bigint bavail*bsize; if >BigInt(Number.MAX_SAFE_INTEGER) throw Error('Storage size exceeds safe numeric range'); return scope and Number(bytes>0n?bytes:0n). Negative values clamp0. Return keys scope,availableBytes. Fresh concurrent default probes can independently resolve before cache fills.

## addPath(path)

If currently eight or more logical entries OR stopped, return before hashing/probing, including repeats. Otherwise hash exact path sha256 hex and install/replace an unknown entry under that hash before checking busy. Unknown entry insertion order: path,scopeId(hash),baseline:null,observedAvailableDropPeakBytes:null,minAvailableBytes:null,quality:'unknown',sampledAt:null. Busy add retains unknown and returns without probing. Idle add sets busy, awaits captured bound probe(path); if stopped after await leave unknown unchanged. Otherwise delete the original unknown key then look up current entry by returned scope. If present, update its measurements only (retain its original path/baseline/quality). If absent, insert a fresh merged entry with scopeId returnedscope, baseline returnedavailable unless this path sealed (then null), minAvailableBytes returnedavailable, sampledAt Date.now(), observedAvailableDropPeakBytes0 unless sealed (then null), quality complete unless sealed (then partial). Sealed membership reads for baseline, drop and quality remain separate in that evaluation order, with Date.now between min and drop. Probe/result getter/hash/timestamp errors inside await-and-update guard are swallowed, potentially after partial mutation; busy resets in finally even if stop. Hash/initial-entry insertion errors before guard propagate. No callback on add, no retry of unknown busy entries here.

## sealing, start, sampling, measurement, snapshot, stop

sealBaseline adds exact path to seal set even stopped; it does not alter existing entries. start only if timer token falsey and not stopped; setInterval referenced callback every2000ms, callback invokes sampler.sample() as bound method and discards return; no immediate sample/unref/catch. Token0 remains falsey and another start registers another interval. start after stop never registers. Register errors propagate.

sample returns immediately when busy/stopped; otherwise busy=true, snapshot current entry OBJECT references in insertion order before awaits. Iterate sequentially; check stopped at top each iteration. Probe each captured entry.path via captured bound probe. After await, if stopped skip updates. If current entry.scopeId differs returned scope: delete its old current key; look up current returned-scope entry. Existing target gets a measurement and continue (no second measurement, original sampled entry discarded). Otherwise mutate captured entry.scopeId to returned scope, quality to partial, install under new key and measure. Same-scope record directly. Each probe/update guard swallows failure and changes captured entry.quality complete->partial only; unknown staysunknown. Collection changes during sampling do not add new iteration entries; captured entries may be overwritten/deleted in live collection and still be processed. No new guards/lease/ownership policy.

Measurement: minAvailableBytes=Math.min(previousMin ?? available,available), then sampledAt=Date.now(), then if baseline!==null set observedAvailableDropPeakBytes=Math.max(0,baseline-minAvailableBytes); baseline null leaves existing drop unchanged. Original measurement getter/mutation partial-failure order retained. Sampling scope migration retains old baseline/min; no recomputed baseline/seal check on migration. After loop, if not stopped call live options.onSample?.(snapshot()), bound options receiver, only compute snapshot if callback exists. Callback/snapshot failure rejects sample; busy resets in finally. No outer swallow for callback.

snapshot returns fresh array/fresh shallow summary objects in collection insertion order, omitting ONLY path and baseline; retain field order from stored objects, scopeId/drop/min/quality/sampledAt and injected values. No deep clone/freeze/coercion, no path or baseline leaked.

stop first sets stopped=true, then if current timer token truthy calls clearInterval(exacttoken). Does not erase timer, cancel in-flight probe, change busy or clear entries; repeated stop clears truthy token again. Token0 is never cleared. Pending add leaves unknown after stop; pending sample skips updates/callback and releases busy after await. Disposal/IO failure quirks are compatibility requirements, not requested improvements. Public declarations and fixed strings/defaults are glue with zero new credit.
