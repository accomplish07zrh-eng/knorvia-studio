# 插件发现与投影独立实现依据

根代理从批准合同和有限公共声明亲自设计、编写七个原公共模块的替代实现及九个新协作模块，共 16 份源码。根没有读取旧插件函数体、旧 bundle 或 source map 来写候选；首稿冻结后，才为分析旧门与候选差异接触独立测试和公开观察。保留八个市场、来源、存储、版本模块只通过已有公共声明消费，不计作本批替换。

独立测试作者先设计并冻结原 41 个用例。验收者在旧基线通过前不读候选；夹具依据公共契约修正错误的命名、模拟校验器和过度具体的预期，保留全部原用例和首次失败。验收准备者另有限读取旧 MCP 模板及 shared 官方头规则，根仅接收抽象行为；据此补两项用例，先在旧版 43 项通过，再验收候选。根对最终缺失的 Claude 项目目录兼容字段作一行修复，没有删除测试。

这是有限角色分离，不是全线程 clean-room 或 OS sandbox。根此前有大量相邻系统上下文，并为模型合同补充读取过模型/telemetry 的保留接口，以及两个旧 model 错误处理文件；该曝光不作为插件实现输入，但不隐瞒。标准字段、第三方库、通过测试与 MIT 头不单独证明原创。

## 主仓范围

接入前七个旧目标摘要完全匹配冻结；九个新路径均确认不存在后创建。16 源码按 v3 原字节复制。独立夹具 11 活动 TypeScript 文件加六个单独入口，共 17 份新测试文件；保留测试进程隔离。加载器只作可移植工具解析、仓内默认根和 `.js` 编译入口支持；边界用例由写死 `.ts` 改为严格核对实际入口在完整 metafile 中出现。

源码与实际 CLI 可达产物均 43 项通过。没有真实市场、插件目录、凭据或模型请求。生成命令、数据目录、启用/停用详情、Hook 能力、MCP 模板与官方来源规则保持批准的公共行为。所有首次失败、机械转换和编译产物绑定见[验收](../../docs/knorvia-exec-plugin-runtime-acceptance.md)；最终逐文件摘要由 `reviews.json` 绑定。

本批独立表达的 16 源码及 17 新测试、规格和记录按文件采用 MIT；八个保留模块、skills scanner、共享协议、Zod 等依赖仍按原声明，不把全仓或所有插件模块提前称为完成。
