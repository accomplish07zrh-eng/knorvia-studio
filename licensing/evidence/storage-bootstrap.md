## 新表达及保留边界

一个可暂停执行序列拥有本次 start/deadline、进度事实和事务所有权；同步及异步驱动只消费通知/等待事件。快照模块只拥有 wx 独占预留的目标。四阶段 BUSY 获取共享预算，后项账本读取当时的持久事实；回调拒绝不伪装为数据库故障，数据库失败和回调失败分别保留首因。连接仍由上层 Store 关闭，没有第二连接、业务队列、accepted 缓存或新增迁移写入者。

| 路径（相对 session-store） | 审查范围                                                                                |
| -------------------------- | --------------------------------------------------------------------------------------- |
| migration-runner.ts        | 两种消费驱动、异步原生 timeout 和顺序清理；没有两份执行流程。                           |
| migration-execution.ts     | 本次执行的唯一可变状态、历史核验、重试、事务、进度和逐项账本观察。                      |
| migration-native-error.ts  | 执行/快照共用的无状态原生 BUSY 与错误投影，保留公开分类器。                             |
| migration-snapshot.ts      | 文件候选、原子预留、VACUUM 与本次失败文件的所有权。旧文件无上游匹配不作为原创依据。     |
| paths.ts                   | 根据批准合同每次解析数据根和目录故障端口，属于很短的标准适配表达。                      |
| errors.ts                  | 根据批准结构保留 Error 原型、native cause、自有可选字段和固定顺序，属于很窄的协议投影。 |

公开类型、字段、错误文本、标准 SQL、常用 Node/SQLite 语法和必要的控制顺序可能与旧表达高度相似，尤其 errors/paths。不能以字段顺序、改名、文件头、重排、拆文件或行数差异证明独立来源，也不对标准表达主张新算法或排他性。逐文件决定同时记录受限输入创作过程和这些限制，MIT 仅覆盖本批经审查的新表达。

原 options.ts、rows.ts、历史 migrations.ts 及三个 SQL 构建器字节未改，原归属继续适用。固定迁移身份 JSON 只记录兼容事实，不复制 SQL，不改变原目录的许可。上层连接门面和其他依赖也不计入本批；根 Apache-2.0、预览身份、第三方依赖及历史发行记录继续保留。
