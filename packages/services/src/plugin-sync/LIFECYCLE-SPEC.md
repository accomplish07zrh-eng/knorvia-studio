## Ownership and sequencing

```text
configured dirs → canonical discovery → candidate IDs → selected archive export
archive import → bounded extraction → validate metadata → ordered plugin entries
   → validate manifest → existing target / ID conflict → staging copy → target rename
   → reread/merge config → private temp JSON write → config rename → success + reserve ID
                                       failure → remove newly created target → failed item
marketplace source → selected dependency closure → local mirrors + retained remote declarations
   → content fingerprint → archive → bounded extraction → validate ID → copy once
all imports → finally remove extraction temp directory
```

No observer, progress or cancellation API exists here; do not add one. No cross-call queue is present. Per-archive plugins are processed serially, and successful imports add to that call's existing-ID map. Preserve errors rather than wrapping arbitrary IO failures; item-level plugin mutation failures become failed results with message, while archive/metadata/cleanup failures may reject the entire method. Do not change config location, permissions, archive limits or guard behavior.

## Common parsing, paths and identity

- A record is non-null non-array object. Required strings must be string and trim nonempty, else Error(`missing ${label}`); return trimmed value.
- Plugin/marketplace ID normalization trims string; empty or containing slash/backslash rejects Error(`invalid plugin id: ${original}`). ID map keys lower-case normalized ID. Do not impose further ID restrictions.
- String-array config values retain only strings with nonempty trim, preserving each original string (do not trim returned dirs).
- Config reads return `{}` only for ENOENT. Other read errors propagate unchanged; malformed JSON propagates its SyntaxError; non-record JSON rejects Error(`invalid json object: ${filePath}`). Unlike settings-sync, invalid config is never silently replaced.
- Config writes mkdir parent; temp path `dirname/.tmp-<basename>-<randomUUID>`; write JSON.stringify(value,null,2) plus newline in UTF-8 with mode 0600; rename temp over final. Preserve existing no-temp-cleanup-on-write/rename-failure behavior; do not add a different atomic adapter or permission policy.
- Path presence for component detection uses lstat/catch false (dangling links present). Directory presence for marketplace paths uses lstat.isDirectory/catch false (symlink directories rejected). Target conflict and marketplace manifest lookup use existsSync (follows links). Keep these distinctions.
- SHA256 text hash is full lower-case hex over UTF-8 string. Candidate ID = SHA256(`${pluginId}:${canonicalRoot}`). Safe directory name: trim, replace each slash/backslash/colon with `-`, fall back to `plugin` when empty; normalize via retained relative-path helper; if normalization throws use `plugin-${SHA256(originalValue).slice(0,8)}`.
- Unique candidate directory: safe basename(canonicalRoot) or plugin name if basename empty; first exact case-sensitive safe name wins. Later same names use safe(`${base}-${SHA256(canonicalRoot).slice(0,8)}`), then reserve; no iterative collision suffixing.

## Manifest/discovery behavior

Read plugin manifest in order `.knorvia-plugin/plugin.json`, `.claude-plugin/plugin.json`, `.codex-plugin/plugin.json`. Read errors continue to next path. The first readable path must parse record JSON with a nonempty trimmed string name; malformed/invalid returns null immediately, without falling through. ID `<name>@inline`. Include trimmed nonempty string description/version only. Component array in this order: skills when manifest has property skills OR lstat(root/skills) succeeds; commands analogously; hooks when property hooks OR root/hooks/hooks.json exists; mcp when property mcpServers OR root/.mcp.json exists. Property presence, not truthiness, matters.

Read user config record; record plugins or `{}`, record plugins.enabledPlugins or `{}`. Boolean override entries keyed by normalized lower-case plugin ID (invalid ID with boolean throws). Read dirs as above.

`listLocalUserPluginCandidates`: iterate config dirs in stored order; resolve raw directory; realpath or resolved fallback on any realpath failure. Deduplicate exact canonical path BEFORE manifest read; skip invalid manifest. Assign unique directory name in this iteration order; compute recursive size, enabled override or true; return candidate with id,name,pluginId,directoryName,path,sizeBytes,enabled,componentTypes and optional description/version/enabledOverride. Finally sort candidates by name.localeCompare. Recursive size uses lstat: files size, directories sum children in readdir order, other entries (incl symlinks) zero; IO failures propagate.

Configured existing-ID map separately iterates dirs without realpath dedup; canonicalization and manifest same; first normalized ID wins. It still reads/validates boolean override keys via the common config reader even though overrides are unused in this map.

`listRemoteUserPluginStatuses`: capture plugin target root, then build configured-ID map. For each requested plugin in input order: normalize directory first, normalize ID, resolve contained target. existsSync(target) has precedence and returns exists:true,path:target,reason:targetExists. Otherwise configured ID returns exists:true,path:existing,reason:samePluginId; otherwise exists:false with no path/reason. Return normalized IDs/directories. Errors reject call unchanged.

## Ordinary plugin archives

Factory max = options.maxArchiveBytes ?? 50*1024*1024 (do not add validation for zero/negative/NaN).

Export: freshly collect candidates; map candidate IDs; each requested pluginIds entry is a candidate ID (not pluginId). Preserve requested order and duplicates. Unknown ID rejects Error(`plugin sync candidate not found: ${id}`). Sum selected sizeBytes including duplicates; if sum > max reject Error(`plugin sync archive exceeds limit: ${size}/${max}`). Resolve each selected candidate.path via realpath in Promise.all for codec entries, archivePath=directoryName. Metadata plugins name/pluginId/directoryName plus enabled only when enabledOverride is defined. After codec, enforce archive.byteLength > max using same error. Return archive, archiveBytes, plugins metadata with id added. Empty selection is allowed.

Import: truthy params.overwrite rejects `plugin sync overwrite is not supported` BEFORE byte-length check; over max rejects `plugin sync archive exceeds limit: ${bytes}/${max}`. Temp root `<dataRoot>/tmp/plugin-sync-<uuid>`. In try/finally, extract with maxExtractedBytes=max; read/JSON-parse metadata file. Require record with plugins array else `invalid plugin sync archive metadata`; every entry must record else `invalid plugin sync archive plugin metadata`. Validate all entries BEFORE any plugin installation: required name/id/directory using labels `plugin metadata name`, `plugin metadata id`, `plugin metadata directory`; normalize ID/directory; retain enabled only boolean. Ignore other metadata.

After metadata validated, capture target plugin root then configured-ID map. For each metadata entry, normalize directory/ID and resolve contained extracted and target paths OUTSIDE per-item try; a guard error rejects archive. Inside try: read extracted manifest; null => `plugin manifest not found: ${directoryName}`; normalized manifest ID mismatch => `plugin manifest id mismatch: ${manifest.pluginId} !== ${pluginId}`. Target exists skip before same-ID skip, using manifest name in successful/skipped result. Skip result includes pluginId,directoryName,status:skipped,path.

For install: mkdir dirname(target); create staging path through contained resolver under targetRoot with `.importing-${safeDirectory(directoryName)}-${uuid}`. cp extracted→staging recursive:true,errorOnExist:true,force:false. Recheck target existsSync; if true throw `plugin target already exists: ${targetPath}`. Rename staging→target then clear staging tracker. Register target in user config. If registration throws, await rm(target,{recursive:true,force:true}) then rethrow; cleanup failures may replace original error. On success add normalized ID→target to map and emit synced result with manifest.name/path. On caught per-item error, if staging tracker exists await rm(staging) (cleanup failure escapes); then emit failed result with metadata.name,normalized ID,directoryName,error=Error.message or String(error), no path. Finally always await rm(tempRoot,{recursive:true,force:true}); cleanup errors propagate even if masking prior result/error. Do not delete pre-existing target directories.

Registration rereads current user config, preserves top-level fields and record plugins fields. Dirs filtered as above; compare resolve(existing) to resolve(target); append resolved target only if absent. Record enabledPlugins or `{}`: if enabledOverride !== undefined, spread existing entries then assign metadata-normalized pluginId key. If absent override, retain nonempty record overrides; other plugins fields survive their existing spread (including malformed enabledPlugins values when not overwritten). Always write config even if path already listed. Merge does not normalize stored existing keys or reorder surviving fields.

## Marketplace manifest and dependency closure

Source kind discriminant is the string `source.source` (not kind). Source kinds accepted: file (required path label `marketplace source file path`, read JSON manifest, sourceRoot=dirname(file)); directory (required label `marketplace source directory path`, choose first existsSync `<root>/marketplace.json`, `<root>/.claude-plugin/marketplace.json`, else `marketplace manifest not found in directory: ${root}`, sourceRoot supplied root); settings (source.marketplace must record else `settings marketplace source is missing marketplace manifest`, no sourceRoot). Other kinds reject `unsupported marketplace source for SSH sync: ${kind || "unknown"}`. No network/git/package fetch occurs for any kind.

Manifest requires record else `marketplace manifest is invalid`; name required label `marketplace name`. Plugins may be array, or record converted by Object.entries order: record entry => `{name:key,...entry}` (explicit name overrides key), nonrecord => `{name:key}`; otherwise empty. Filter nonrecord array entries. Each plugin requires trimmed name label `marketplace plugin name`; dependencies retain only string entries with nonempty trim without trimming them yet; preserve raw object/source (source property present when not undefined). Description retained if any string, including empty/whitespace. pluginRoot is first nonempty trimmed top-level string then metadata record's nonempty trimmed pluginRoot string. Preserve raw manifest.

Export normalizes marketplaceId as plugin ID, required/trimmed pluginNames via label `plugin name`, insertion-order dedup; zero names => `missing marketplace plugin names`. Load source; manifest name must exactly equal ID else `marketplace id mismatch: ${name} !== ${id}`. Closure map by exact name (last duplicate manifest entry wins); for selected names in order, depth-first PREORDER: required/trim label `marketplace plugin name`, skip visited; missing => `marketplace plugin not found: ${name}`; mark visited and append before traversing dependencies (cycles permitted). Dependency uses last @: absent => trimmed string; suffix exactly marketplaceId => prefix; else error `cross-marketplace dependency is not supported for SSH source mirror: ${originalDependency} required by ${requiredBy}`. Preserve requiredBy quirk: visit(name,requiredBy) normalizes all its dependencies using supplied requiredBy, then recursive visit receives current entry.name. Roots start with requiredBy=root name.

## Marketplace source resolution and mirroring

An entry source is remote only when record.source equals one of github,git,url,git-subdir,npm,pip; preserve those declarations without copying or network access. Otherwise resolve local directory:

- String source passes path resolver with label `${entry.name} source`.
- Record source==='directory' and string path passes resolver with label `${entry.name} directory source`, allowing absolute source only for settings/no-sourceRoot. Other sources fall back to name directory.
- Fallback without sourceRoot rejects `cannot mirror local marketplace plugin source without source root: ${entry.name}`. Otherwise base dir below; resolve entry.name through retained path guard with label `unsafe marketplace plugin source path`; require directoryExists else `local marketplace plugin source does not exist: ${resolvedFallback}`.
- Path resolver required-trims source path, removes exactly one leading `./` for relative resolution. If no sourceRoot and absolute-settings-directory allowed: reject nonabsolute with `cannot mirror local marketplace plugin source without source root: ${originalSourcePath}`; resolve absolute, require directoryExists else `local marketplace plugin source does not exist: ${originalSourcePath}`. If no root otherwise, same missing-root error. With root, use guarded relative path under base; require directoryExists else same nonexistence error using original source path. Do not newly permit absolute file-based/string sources.
- Base dir: no sourceRoot => `cannot resolve marketplace plugin source root`. No pluginRoot => sourceRoot. Otherwise guarded pluginRoot with label `unsafe marketplace pluginRoot`; use it if existsSync, else fallback sourceRoot (not directoryExists).
- All resolved local directories must have a valid readable plugin manifest; otherwise `local marketplace plugin source is missing plugin manifest: ${root}`. Do not weaken this protection; no arbitrary directory copying.

Mirror entries prepared concurrently via Promise.all over closure. Local archive-relative source `plugins/${safeDirectory(entry.name)}`; do not dedup sanitized names. Mirror manifest: copy raw then delete top-level pluginRoot, spread it, overwrite name with normalized manifest.name, include description override only if truthy (raw field otherwise remains). If any local mirror exists, metadata becomes record raw metadata or `{}` plus pluginRoot:'plugins'; otherwise leave raw metadata unchanged. Plugins replaced with closure entries in order: raw entry spread plus normalized name, local source rewritten to `./${relativeSource segments after first joined /}`, remote source unchanged. Preserve dependencies raw. JSON manifest is two-space indent plus newline.

Size = UTF-8 manifest bytes plus sum local recursive sizes (remote0), compared >max using `plugin marketplace source archive exceeds limit: ${size}/${max}`. Compute local content fingerprints concurrently, remote null. Fingerprint is recursive SHA256: file hash updates string `file\0` then raw bytes; directory hash updates `dir\0`, sorts dirent children by name.localeCompare, then for each child name + `\0` + recursively computed lowercase hex + `\0`; unsupported entry (incl symlink) throws `unsupported plugin archive source: ${path}`. Directory name = safe(marketplaceId) + '-' + first12 SHA256(JSON.stringify({manifestContent,sourceFingerprints})) with object property order as shown. Content fingerprint, not paths/mtime, identifies unchanged mirror.

Archive entries: `<directoryName>/marketplace.json` inline content first, then local mirror paths in closure order. Metadata `{plugins:[],marketplaceSources:[{marketplaceId,directoryName}]}`. Result archive,archiveBytes,marketplaceId,pluginNames=closure names. Outer export enforces compressed archive size >max with same marketplace limit error.

## Marketplace import

Reject truthy overwrite `plugin marketplace source overwrite is not supported`; check compressed limit. Temp `<dataRoot>/tmp/plugin-marketplace-source-<uuid>`, try/finally extract with maxExtractedBytes. Metadata requires record with marketplaceSources array else `invalid plugin marketplace source archive metadata`; length exactly1 else `plugin marketplace source archive must contain one marketplace`; entry record else `invalid plugin marketplace source metadata`. Required marketplaceId label `marketplace source id`, normalize ID; directory label `marketplace source directory`, normalize relative path. No requirement for plugins array here.

Normalize directory again and resolve extracted path; read `<extracted>/marketplace.json` using manifest parser. Name mismatch => `marketplace source archive id mismatch: ${manifest.name} !== ${metadata.marketplaceId}`. Target under `<pluginRoot>/marketplace-sources/<directoryName>` using guarded resolver. existsSync(target) => skipped, no content revalidation. Otherwise mkdir parent, cp recursive:true,errorOnExist:true,force:false directly to target (no staging/config registration), return synced. Return marketplaceId,path,status. No target rollback on copy failure. Always rm extraction temp in finally; errors propagate unchanged.
