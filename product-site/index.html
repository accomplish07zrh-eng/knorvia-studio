群聊

@ 指定成员，或交给主持人。任务模式下主持人规划、派发、复核，一直推进到完成、真实阻塞或你喊停。

节点画布支持串行、并行、条件、汇合、人工确认与有限重试；内置模板，能接创作节点，历史可恢复，结果可对比。

图片与视频生成，兼容 OpenAI Images、可配置 JSON API 或 ComfyUI，也能作为工作流节点。

COMPUTER USE

电脑控制，
看得见，停得住。

  1. 01选窗口列出桌面上的窗口，由你指定这次要操作哪一个。
  2. 02当轮授权每一轮都要你批准目标窗口，不会存成永久许可。
  3. 03看截图只截取被授权的窗口，交给支持图像的模型理解。
  4. 04动手操作点击、输入、滚动、拖动，坐标严格对应截图。
  5. 05再看一眼每个动作之后重新截图，确认效果再继续。
  6. 06随时喊停停止后，后续动作全部拒绝，也不会自动重放。

Windows x64 · 本机 Knorvia 内核 · 需要支持图像的模型
插件默认关闭，在「插件」中启用。前台操作可能移动鼠标或切换窗口；不支持系统安全桌面与管理员窗口。

KNORVIA
A GROUP TASK

一次群任务，从开始到完成。

01 / 规划

主持人拆解目标

把一句话需求拆成可执行的步骤，写清谁做什么。

02 / 派发

成员各开独立会话

不同内核并肩工作，彼此的上下文互不串扰。

03 / 隔离

默认在隔离目录修改

真实项目不会被直接改动，每位成员有自己的沙盘。

04 / 复核

逐文件审阅再应用

每个文件单独查看、单独应用；源文件被改过会标出冲突，绝不覆盖。

05 / 持续

推进到真正完成

不设固定轮次：直到完成、遇到真实阻塞，或你喊停。

06 / 完成

安静地交付。

你只需要看结果。
